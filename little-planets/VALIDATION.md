# Little Planets 0.8 Aurora — проверка 20 октября 2026

Среда: Linux x86_64, Node.js 24.19.0, npm 11.9.0, Chromium с программным WebGL. Изменения только в `little-planets`, поверх `384d199de9e30825cc3a76095a6618bbdd53a5e8` ветки `little-planets-mvp`.

## Результаты

- `npm test`: **80 тестов, 8 файлов, все прошли**. Сохранены проверки кубических миров, добычи/строительства блоков, плавной камеры/высоты, автоматического фундамента, программ роботов, боя/респауна, сада/интерьеров, гарпуна, полёта, Telegram HMAC, SQLite/CAS и совместимости сохранений.
- Новый `tests/aurora.test.ts`: 1 206 кубических миров / 61 созвездие / 30 видов сырья; три уникальных ресурса на мир, стабильные доли с суммой 100%; ограничения дальности сканера, десять уровней и сохранение удалённого открытия; создание удалённых миров по мере открытия; сохранение прогресса 0.6/0.7 с новыми полями профиля/ангара.
- Поглотитель: после 100 единиц добычи выход точно соответствует скану. Проверены реальный рост скорости, нулевая стоимость улучшений и геометрические размеры пятого уровня: почти вся грань и высота средней планеты. Проверены рост геометрии сканера, бесплатные строительные блоки и обычный склад с настоящим запасом без двойной модели.
- Производство: каждый из 28 рецептов использует два вида входов; новые ступени объединяют материалы предыдущего уровня. Станция без транспорта не берёт сырьё со склада. Гусеничный логист действительно движется, загружает оба входа, везёт их в буфер, забирает продукцию и возвращает на склад. Проверено сохранение грузов, отсутствие повторного выпуска по тому же времени и путь через противоположные грани куба.
- Межпланетная логистика: простой маршрут переводится в настоящую программу дрона. Неполные партии грузятся, летят и выгружаются с сохранением баланса ресурса. Регрессионная цепочка **сырьё А → склад Б → гусеничный транспорт → переработка Б → склад Б → грузовой дрон → склад Родной** прошла.
- Ангар: созданы все девять сочетаний классов/MK; сохраняются фюзеляж, крылья, окраска и выбранный корабль. Выбранная модель задаёт реальную скорость полёта. Профиль фиксирует прибытия и подключённое время по планетам, данные сохраняются после перезагрузки.
- `npm run test:browser`: **Cubeworks + Journey + Aurora прошли последовательно**. Прежние сценарии проверяют 1100×800, 390×844 и 844×390, добычу/установку/перезагрузку, редактирование графа, яму/прозрачность, неподвижное окружение, переходы граней, первый вид, предметы, блок под ногами, навыки, день/ночь, строительство и сохранённую поездку по тросу.
- `test:aurora`: нажатие на реальную модель здания, улучшение сканера, цветная/недоступная цель, проценты ресурсов и сохранение скана; паспорт с печатью; модульный корабль без списания ресурсов; настройка гусеничного и межпланетного маршрутов. Проверена добыча поглотителя при неподвижном игроке. На 390×844 и 844×390 карта и профиль помещаются без горизонтального переполнения. Из кабины проверены физический подлёт, появление кнопки посадки и действительное прибытие. Ошибок JavaScript, шейдеров или WebGL не обнаружено.
- `npm run test:production`: **прошёл на production-сборке**. Проверены запрет локального входа, подписанная Telegram-идентичность, URL-префикс `/planets/`, SDK/fullscreen/safe areas, бесплатное создание устройств через настоящий API и SQLite, автоматический подход к кораблю из карты, ручное управление/автопилот, перезагрузка в полёте и подтверждённая сервером посадка.
- Скриншоты карты, паспорта, верфи, кабины и станции просмотрены. Финальная визуальная сцена дополнительно проверяет промышленную модель пятого уровня с оборудованием крыши и обзор с ребра планеты.
- `npm run build` / `npm run package:server`: TypeScript и Vite прошли. Основной JS около 875 КБ / 250 КБ gzip. Есть предупреждения о размере чанка и аннотациях стороннего Zod; ошибок сборки нет.
- `npm run test:upgrade`: проверены успешное обновление, остановка при повреждённом сохранении, резервные копии `.env`/приложения/SQLite и автоматический откат после неудачного health check. Всё выполняется во временных каталогах с изолированными заглушками systemd.
- `npm run test:runtime`: итоговый архив устанавливается только с production-зависимостями, выдаёт HTML и `/api/health`, отклоняет API-запросы без Telegram-авторизации.

## Практические границы

Поглотители и машины симулируются во время открытой игры на всех освоенных мирах. Отдельного непрерывного офлайн-планировщика нет. Трюм и броня корабля показывают характеристики проекта; отдельный космический бой и загрузка его трюма не реализованы. Перевозки ресурсов выполняются грузовыми дронами. Планеты и составы воспроизводимы, сохранение каждого пользователя отдельно.

Формат 6 сохраняет прежний прогресс; прототипные версии 1–5 начинают новую игру. В старых оплаченных заданиях переработки выход теперь появляется в буфере станции и забирается гусеничным транспортом. Ходьба внутри горизонтальных тоннелей по-прежнему не является отдельным физическим режимом.

Нативные Telegram-клиенты на физических телефонах и HTTPS действующего VPS не проверялись. Работающий сервер, `street-racing`, DNS и Caddy не изменялись. Скриншоты находятся в игнорируемом `test-results`.
