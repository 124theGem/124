# Проверка Odyssey 0.4 — 18 октября 2026

## Сборка и правила

Node.js 24.19.0, npm 11.9.0. `npm run build` проверяет TypeScript и собирает production-клиент. Игровые изображения, музыка и шрифты не требуют внешних сервисов; Telegram SDK включён в пакет. Предупреждения Vite о размере чанка и комментариях Zod не мешают сборке.

`npm test` — **52/52**: 21 базовый тест, 16 Frontiers, 9 Odyssey, 6 серверных.

Новые проверки:

- Восемь разных сферических биомов, несколько радиусов, обход полного круга на каждой сфере и корректные координаты у полюсов.
- Вся геометрия поверхности: постоянный цвет внутри каждой отдельной квадратной плитки, направленные наружу треугольники. Проверяются все плитки восьми сфер.
- Создание кустов, 900 колосков на Орбисе, деревьев, пещер, водопадов и вулканов; конечные матрицы после анимации воды и дыма.
- **1 406 маршрутов**: перелёт между каждой парой из всех 38 миров, включая 24 обнаруживаемые экспедиции. Корабль обходит твёрдые тела и достигает маяка на допустимой скорости.
- Тяга, поворот, изменение высоты, торможение и устойчивая взаимно перпендикулярная ориентация корабля.
- Автопилот после ручного сближения с обратной стороной планеты сначала набирает безопасную высоту и рассчитывает новый маршрут. То же проверено при смене курса рядом с поверхностью.
- Исходная планета сохраняется до посадки; инвентарь сохраняется. Посадка издалека, действия на поверхности во время полёта, неизвестные цели, внедрение координат и ускорение часов команд отклоняются.
- Незавершённый полёт записывается в настоящую SQLite, читается после повторного открытия и продолжает принимать команды. Пользователи изолированы.
- Старые форматы 1/2/3 начинают новую игру формата 4 по ранее указанному предпочтению пользователя.

Существующие тесты покрывают базу, сад, крафт, комнаты и мебель, добывающие модули, события, бой и экипировку, Telegram HMAC, ревизии и сохранения.

## Браузер: новые миры и полёт

`npm run test:odyssey` прошёл с настоящими действиями в Chromium:

- Все восемь сфер загружены, осмотрены на поверхности и в обзоре. На каждой — более 4 000 отдельных плиток, 72 куста, звёздный фон и соседние миры. В проверенных сценах меньше 180 вызовов отрисовки.
- Клавиатурой выполнены движение по сфере и ручной полёт: тяга, поворот, наклон и торможение.
- Проверена горизонтальная раскладка кабины 844×390: элементы в границах экрана, без горизонтальной прокрутки и взаимных перекрытий.
- Атлас открывается в космосе, позволяет выбрать курс и вернуться к исходному миру. Во время спуска смена курса и автопилота блокируется, исходная планета сохраняется до завершения посадки.
- Два настоящих перелёта: Орбис → Вердия → Родная. Посадка разрешается после сближения и замедления. Подробная поверхность загружается до приземления; после посадки восстанавливается правильная вертикаль персонажа.
- Перезагрузка в космосе продолжает сохранённый полёт; перезагрузка после посадки сохраняет посещённый мир.
- JavaScript-ошибок нет. Снимки: `test-results/odyssey-*-surface.png`, `odyssey-*-overview.png`, `odyssey-manual-space.png`, `odyssey-flight-landscape.png`, `odyssey-verdia-landed.png`.

`node --import tsx tests/flight-touch-browser.mjs` прошёл отдельно: портретная кабина 390×844 помещается на экране без перекрытий. Два настоящих сенсорных указателя одновременно управляют тягой джойстика и наклоном; после отпускания обоих управление сбрасывается. Снимок — `test-results/odyssey-flight-touch-portrait.png`.

## Production через Telegram API

`npm run test:production` прошёл с production-сборкой, настоящим SDK, подписанным тестовым initData, SQLite и прокси, удаляющим префикс `/planets/`:

- Обычный браузерный вход заблокирован; HTML, assets, SDK и защищённый API доступны по правильным путям.
- Проверены запрос fullscreen и безопасные отступы через имитацию Telegram host.
- Строительство сохраняется через API и переживает перезагрузку.
- Выполнен серверный перелёт Родная → Орбис: подтверждённая сервером исходная планета, движение в пространстве, перезагрузка посреди полёта, возобновление автопилота и посадка. После посадки API возвращает Орбис, `flight: null` и прежнюю домашнюю постройку.
- Снимок подлёта: `test-results/telegram-production-approach.png`.

## Дополнительные регрессии и поставка

- `npm run test:browser`: грядки, настоящий рост и сбор, строительство, крафт, инвентарь, вход/мебель/выход дома, четыре перелёта с неизменным инвентарём и постройками, вертикальный взлёт с дымом, сенсорный джойстик, fullscreen и границы/неперекрытие интерфейса в двух ориентациях.
- `npm run test:frontiers`: иллюстрированные рецепты, крафт/экипировка, звук и настройки, случайное открытие и поиск, полёт на Ферру, реальные атаки/урон/броня/добыча. Затем **120.8 м** непрерывной ходьбы по Орбису через оба полюса, постоянный радиус персонажа, обзор, перезагрузка, вылет со сферы и посадка домой.
- `npm run test:events`: видимые метеорит, ветер, дождь, гроза и ураган; настоящий клик по метеориту и однократная награда.
- `node --import tsx tests/expedition-browser.mjs`: на экспедиционной планете через интерфейс построен добывающий модуль подходящего ресурса.
- `node --import tsx tests/windows-browser.mjs`: мебель и длинный каталог крафта закрываются после прокрутки в портретном и горизонтальном режимах.

`npm run package:server` создаёт готовый `releases/little-planets-odyssey-v4.tar.gz` и SHA-256. Внутри production-клиент, сервер и shared-код, lockfile и пример настроек; настоящего `.env`, токена, базы, тестовых данных и node_modules нет.

`npm run test:upgrade` проверяет успех, повреждённое сохранение и откат при провале health check, используя временные каталоги, настоящую SQLite и HTTP, а также заглушки systemd/смены владельца/npm. Проверяется сохранение настроек и резервной копии.

`npm run test:runtime` устанавливает 88 production-зависимостей во временную распаковку пакета и проверяет HTML, health endpoint и защиту API. Пересборка и dev-зависимости на VPS не требуются.

## Пределы проверки

Программный Chromium и плотность пикселей 0.5 не доказывают FPS физического телефона. Настоящие Telegram Android/iOS, реальный токен и публичный HTTPS из этой среды не проверялись. Команды на SSH-сервере пользователя автоматически не выполнялись.

Сферы имеют проходимую сферическую основу и декоративный рельеф: коллизии скал, урон от лавы и отдельные подземные уровни пока отсутствуют. Строительство и грядки на сферах отключены. Перелёт аркадный, посадка у маяка; орбитальная гравитация и топливо не моделируются. Небесные планеты на поверхности стилизованы для ортографической камеры; объекты в космосе имеют постоянные координаты. Сканер имеет конечный пул 24 дополнительных экспедиций.
