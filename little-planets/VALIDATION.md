# Little Planets 0.7 — проверка 20 октября 2026

Среда: Linux x86_64, Node.js 24.19.0, npm 11.9.0, Chromium с программным WebGL. Изменения выполнены только в `little-planets` поверх коммита `972023ef74e3f3016e79d666d6ae8f208310ae1a` ветки `little-planets-mvp`.

## Пройдено

- `npm test`: **64 теста, 7 файлов, все прошли**. Сохраняются проверки шести граней, 24 направленных переходов, добычи и строительства настоящих блоков, программ сборщиков/охотников, складов, переработки, межпланетного груза, респауна врагов, боя, сада, интерьеров, полёта и Telegram HMAC/SQLite/CAS.
- Новые модельные проверки: неподвижный угол камеры на ребре/вершине; постепенный подъём и падение без перескока поверхности; промежуточные координаты машин; автоматический фундамент на неровной земле, заполнение ям и удаление растительности; составные архитектурные модели всех типов зданий; сохранение пустой программы; выбор только имеющихся предметов и реальная смена боевого оружия; цикл дня/ночи; опыт, очки навыков и бонус добычи; гарпунный маршрут, ограничения в пути, сохранение, отмена и однократное прибытие по серверному времени.
- Совместимость с 0.6: новая схема и настоящая SQLite добавляют поля к сохранению формата 6 без сброса инвентаря, рельефа, программ и ревизии. Добавление новых полей фиксируется в базе один раз, поэтому солнечный цикл не начинается заново при чтении.
- `npm run test:browser`: **оба сценария прошли**. `test:cubeworks` проверяет desktop 1100×800, portrait 390×844 и landscape 844×390: клавиатуру/джойстик, добычу и установку, перезагрузку, создание машин, параметры, перетаскивание/соединение блоков, яму, прозрачность, неподвижные мировые координаты облаков/неба/вихря и переход между гранями.
- Новый `test:journey` проверяет переключение предметов и оружия, блок под ногами с подъёмом, удаление всех блоков программы и повторное открытие/перезагрузку, расход очка навыка, перспективный вид от первого лица и движение, постройку с подготовкой фундамента, поездку по тросу с перезагрузкой в пути и фактическое прибытие. Отдельные сцены проверяют ночной первый вид на двух мобильных размерах, отсутствие горизонтального переполнения, движение реального сборщика и видимых врагов, остановку камеры на ребре и вершине. Ошибок шейдеров/WebGL или JavaScript не обнаружено.
- Изображения первого вида, архитектуры, ночи, рёбер/вершины и троса просмотрены вручную. Камера троса следует за перемещением героя без отставания на большой скорости; сглаживается её направление обзора. После утолщения видимого троса дополнительно проверены близкая камера и фактическое прибытие.
- `npm run build` / `npm run package:server`: TypeScript и production-сборка прошли. Предупреждения сборщика относятся к аннотациям стороннего Zod и размеру основного JS (~836 КБ, ~236 КБ gzip); ошибок сборки нет.
- `npm run test:production`: прошёл. Production запрещает локальный вход; проверены подписанная Telegram-авторизация, SDK/safe areas/fullscreen, префикс `/planets/`, создание устройств и сохранение через настоящий API/SQLite, управляемый полёт, перезагрузка в полёте и посадка.
- `npm run test:upgrade`: успех, повреждённое сохранение и откат после провала health check прошли. Используются настоящая временная SQLite и изолированные заглушки systemd/владельцев/npm; работающий сервер не затрагивается.
- `npm run test:runtime`: итоговый архив распакован и установлен только с production-зависимостями; проверены HTML, `/api/health` и отказ API без Telegram-авторизации.

## Практические границы

Прогресс формата 6 сохраняется; версии 1–5 начинают новую игру. Машины симулируются при открытой игре на всех мирах сохранения; непрерывного офлайн-планировщика нет. Персонаж следует верхней доступной поверхности: пустоты и навесы настоящие, но отдельной физики ходьбы внутри горизонтальных тоннелей нет. Глубинное ядро не разрушается. Гарпун использует сохранённый безопасный маршрут между открытыми планетами; отдельной симуляции упругости троса нет.

Нативные Telegram-клиенты на физических телефонах и HTTPS действующего VPS не проверялись. `street-racing`, работающий сервер, Caddy и DNS не изменялись. Скриншоты создаются в игнорируемом `test-results`. Исторические браузерные сценарии сфер 0.4/0.5 заменены актуальными `test:cubeworks` и `test:journey`.
