# Little Planets 0.10 Outfit — проверка 20 октября 2026

Среда: Linux x86_64, Node.js 24.19.0, npm 11.9.0, Chromium с программным WebGL. Изменения только в `little-planets`, поверх `68738bd8e8449743cffd9d54cd86431b5b0912b7` ветки `little-planets-mvp`.

## Проверенные изменения

- «Системы колонии» прокручиваются жестом и колесом, в том числе на горизонтальном экране. Кнопка создания устройства и выбор типа вынесены наверх окна автоматизации.
- Все шесть типов устройств сначала создаются в инвентарь. Установка проверяет участок и расходует один комплект только при успехе; машины затем исполняют настоящие программы.
- Кирка использует отдельную кнопку удара с удержанием, подсветку блока и анимацию рук. Добыча не открывает контекстное окно; материалы поступают в инвентарь, изменения земли сохраняются. Выбор кирки из строительства действительно берёт её в руки.
- Миникарта удалена. Увеличены все планеты примерно на 20% с округлением: грань Родной теперь 46×46. Однократное преобразование сохранений переносит координаты, грядки и изменённые воксели, сохраняя программы, ресурсы и производство.
- Верфь создаёт именованный корабль в инвентарь. Установка создаёт настоящую площадку и выравнивает основание; прежний корабль возвращается в инвентарь. Модель обновляется без пересоздания сцены или сброса камеры. Взлёт, полёт и посадка используют сохранённые координаты площадок; пустая площадка не создаёт корабль.

## Результаты

- `npm test`: **95 тестов, 10 файлов прошли**. Новые проверки охватывают шесть типов комплектов, учёт ресурсов, запрет повторной/удалённой установки, обязательную кирку в руках, размеры всех планет, корабль и заменяемый ангар, обновление модели без замены сцены, вылет/возврат на свою площадку и однократный перенос старой геометрии с сохранением блоков, урожая и программ.
- Браузерные сценарии запускаются последовательно: `test:cubeworks`, `test:journey`, `test:aurora`, `test:flightdeck`, `test:outfit`. **Все прошли** (Flight Deck: сначала три размера окон, затем повтор взаимодействий после исправления проекции тестового нажатия). Сохранены проверки блоков, программ и их удаления, реальной логистики, прозрачности, первого вида, навыков, троса, дня/ночи, плавного движения и камеры на рёбрах/углах. В Aurora проверены сканы, состав ресурсов, улучшения, физические здания, верфь и паспорт.
- Новый `test:outfit` проверяет прокрутку настоящим сенсорным жестом на 844×390 и колесом на 390×844, отсутствие миникарты, 46-клеточную грань, создание гусеничного логиста через UI, появление в инвентаре, установку и перезагрузку. Отдельно проверяет выбор кирки после пустых рук, одиночный удар и удержание без меню, рост запаса камня и сохранение ямы. На верфи создаётся модульный грузовой корабль с именем; через инвентарь устанавливается новая площадка, открывается кабина и сохраняется полёт из фактического места.
- `npm run test:production`: прошёл на итоговой сборке. Проверены запрет локального входа, подписанная Telegram-идентичность, `/planets/`, SDK, SQLite, fullscreen/safe areas, создание и размещение устройств через настоящий API, управляемый полёт, перезагрузка в полёте и подтверждённая сервером посадка.
- `npm run build` и `npm run package:server`: TypeScript и Vite прошли. Основной JS около 895 КБ / 257 КБ gzip. Есть предупреждения о размере чанка и аннотациях стороннего Zod; ошибок сборки нет.
- `npm run test:upgrade`: итоговый архив проверен на успешное обновление, отказ при повреждённом сохранении, резервные копии приложения/SQLite/.env и автоматический откат в изолированных временных каталогах.
- `npm run test:runtime`: итоговый архив устанавливается только с production-зависимостями; HTML, health и защищённый API работают.

## Практические границы

Формат сохранений 6 сохраняется с полем масштаба. Строительство бесплатно для всех тестовых игроков; логистика и переработка используют реальные ресурсы. Поглотители и машины симулируются во время открытой игры; отдельного офлайн-планировщика нет. Отдельный космический бой и загрузка трюма корабля по-прежнему не добавлены. Перевозки выполняются грузовыми дронами. На каждой планете одна активная площадка.

Нативные Telegram-клиенты на физических телефонах и HTTPS действующего VPS не проверялись. Работающий сервер, `street-racing`, DNS и Caddy не изменялись. Скриншоты находятся в игнорируемом `test-results`.
