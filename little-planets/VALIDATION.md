# Проверка Frontiers 0.3 — 18 октября 2026

## Установка и сборка

Node.js 24.19.0, npm 11.9.0, Chromium `/usr/bin/chromium` с программным WebGL.

- Повторно выполнено `npm ci --no-audit --no-fund` по lockfile.
- `npm run build` — TypeScript и production-сборка проходят. JS около 707 kB / 193 kB gzip, CSS около 30 kB / 6.6 kB gzip. Предупреждения Vite о размере чанка и комментариях Zod остаются, ошибок нет.
- `npm run dev` и реальные HTTP-запросы подтверждают frontend 5174 и backend `/api/health` на 8003.
- Внешние игровые изображения, музыка и шрифты не нужны. Иллюстрации мастерской строятся из моделей, звук синтезируется Web Audio; Telegram SDK хранится локально.

## Правила и сервер — 42/42

`npm test`: 21 базовый тест, 16 тестов Frontiers, 5 серверных.

Базовые проверки покрывают размер Родной, ограничения зон строительства, коллизии, сад, добывающие модули и их офлайн-буфер, крафт, лабораторию, комнату и мебель, сохранение внутри дома, выход, метеорит и перелёты.

Frontiers проверяет:

- Создание и надевание оружия/брони, проверку слотов и владения, снятие предметов.
- Лабораторные ограничения бластера и продвинутой брони.
- Дистанцию удара, задержку, урон, однократную награду, снижение входящего урона бронёй.
- Поражение с возвращением домой и сохранением экипировки; ограниченный шаг симуляции вместо часов офлайн-атак.
- Сериализацию здоровья, экипировки, врагов и открытых миров.
- Начальные миры, 24 неповторяющиеся находки сканера, запрет полёта в неизвестный мир, расстояние до корабля, отклонение несуществующих ID.
- Детерминированные различные раскладки ресурсов экспедиций с одинаковым размером и биомом.
- Все пять погодных событий по сохранённой временной шкале.
- Сферические координаты, шов долготы, оба полюса, кратчайшую дистанцию по поверхности и полный круг 120 м через оба полюса с параллельным переносом направления.

Сервер проверяет Telegram HMAC, signature, подмену/срок входа, изоляцию пользователей, SQLite после повторного открытия, конфликт ревизий, неверные действия и отсутствие development-login. По прямому запросу пользователя старые форматы начинают новый мир: проверены новая версия 3, сброс прогресса и сохранение результата в SQLite при повторном входе.

`npm run test:runtime` реально установил 88 production-зависимостей по lockfile во временной распаковке пакета и проверил HTML, health endpoint и запрет неавторизованного API. Работает без dev-зависимостей.

## Пределы проверок

Браузеры используют плотность пикселей 0.5 при CSS-размерах настольного и мобильных экранов; интерфейс также осмотрен при 0.75. Программный Chromium не доказывает FPS реального телефона. Web Audio создаёт и запускает граф звука, но физический динамик и субъективное звучание в облаке не прослушивались.

Настоящие Android/iOS Telegram, реальный токен и публичный HTTPS из этой среды не проверялись. Команды на SSH-сервере пользователя автоматически не исполнялись. Для установки подготовлен отдельный сценарий с резервной копией и откатом.

Это прототип: сфера имеет гладкую проходимую поверхность без строительства; сканер имеет конечный пул 24 экспедиций. Старый прогресс намеренно не переносится по запросу пользователя, настройки бота сохраняются.
