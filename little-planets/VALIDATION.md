# Little Planets 0.9 Flight Deck — проверка 20 октября 2026

Среда: Linux x86_64, Node.js 24.19.0, npm 11.9.0, Chromium с программным WebGL. Изменения только в `little-planets`, поверх `b234b16bf031ef3b7b76439d71eba0dadb7cac6d` ветки `little-planets-mvp`.

## Проверенные изменения

- Новая общая оболочка окон: навигация, заголовок, статус сохранения; полностью заменены прежние каскады CSS. Новые HUD, пиктограммы, карточки строительства, каталог с превью настоящих моделей. Инстансированные детали учитываются в иллюстрациях.
- Корабль выбирается по реальной геометрии. Открывается собственное меню с входом в кабину и отдельной картой маршрутов. Выбранный ранее гарпун не перенаправляет действие корабля на трос. Серверная команда `boardShip` проверяет близость и запускает сохраняемый полёт без требования выбрать другую планету.
- Успешная постройка сбрасывает выбранный чертёж. Существующие здания доступны для взаимодействия и при активном размещении. Есть видимый индикатор и отмена размещения.

## Результаты

- `npm test`: **82 теста, 9 файлов прошли**. Две новые регрессии проверяют вход с гарпуном, сохранение кабины, последующий реальный курс и посадку, ограничение близости к кораблю и прежний запрет обычного маршрута на текущую планету. Прежние проверки мира, физики, производственных цепочек, программ, боя, сохранений и Telegram API сохранены.
- `npm run test:browser`: **Cubeworks + Journey + Aurora + Flight Deck прошли последовательно**. Сохранены проверки добычи и установки блоков, перезагрузки, соединения/перетаскивания программ, удаления блоков, логистики, прозрачности, первого вида, прокачки, гарпуна, плавного движения, стабильной камеры на рёбрах/углах, дня и ночи, сканера, верфи и посадки.
- Новый `test:flightdeck`: все семь основных разделов и навигация проверены на 1440×1000, 390×844 и 844×390 без горизонтального переполнения. Создан настоящий дом, чертёж сброшен, следующее нажатие сразу открыло управление без выбора кирки. Отмена следующего чертежа работает. После выбранного гарпуна нажатие корабля открывает собственное меню, вход создаёт полёт без троса, карта использует корабль, перезагрузка сохраняет кабину.
- Вручную просмотрены скриншоты нового HUD, инвентаря, производства, строительства, программного редактора, здания, карты, верфи и мобильного каталога. На узком экране действия выбранного предмета/рецепта находятся выше списка.
- `npm run test:production`: прошёл на итоговой сборке. Проверены запрет локального входа, подписанная Telegram-идентичность, `/planets/` и SDK, SQLite, fullscreen/safe areas, бесплатные устройства через настоящий API, подход к кораблю, ручной полёт/автопилот, перезагрузка в полёте и подтверждённая сервером посадка.
- `npm run build` и `npm run package:server`: TypeScript и Vite прошли. Основной JS около 884 КБ / 254 КБ gzip. Есть предупреждения о размере чанка и аннотациях стороннего Zod; ошибок сборки нет.
- `npm run test:upgrade`: успешное обновление, отказ при повреждённом сохранении, резервные копии `.env`/приложения/SQLite и автоматический откат проверены в изолированных временных каталогах.
- `npm run test:runtime`: новый архив установлен только с production-зависимостями; HTML, health и защищённый API работают.

Формат сохранений 6 сохраняется. Строительство бесплатно для всех тестовых игроков; логистика и переработка используют реальные ресурсы. Перевозки выполняются грузовыми дронами.
