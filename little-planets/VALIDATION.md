# Little Planets 0.11 First Light — проверка 20 октября 2026

Среда: Linux x86_64, Node.js 24.19.0, npm 11.9.0, Chromium с программным WebGL. Изменения только в `little-planets`, поверх `3ed397c7c588001867f21302b05408b539fae5cd` ветки `little-planets-mvp`.

## Реализованное поведение

- Настоящие новые игры в локальном режиме и через Telegram начинают вступление. Дом находится ближе к месту посадки; три растения, маленький робот ПИКО и железный метеорит существуют в мире и выбираются нажатием. Вступительная камера плавно осматривает место посадки. Радио ПИКО сообщает о четырёх других планетах.
- Сохраняемая цепочка: три разных растения → метеоритное железо киркой → ремонт за 3 биоволокна и 3 железа → ЗАПУСТИТЬ → плавное отдаление камеры к системе из пяти миров. Бесплатное строительство не отменяет оплату ремонта. Ранние вылет, гарпун и создание другого корабля не обходят задание. Перезагрузка не повторяет награды и восстанавливает текущий этап, включая показ системы. Существующие сохранения сразу продолжают основную игру.
- Новое здание телескопа с оптической трубой, опорами, солнечными панелями и пультом. Физическое нажатие открывает меню целей; карта также позволяет рассмотреть выбранный сигнал без сканирования ресурсов или открытия маршрута. Отдельная сцена использует геометрию выбранного мира и его сохранённые изменения. Наблюдение не переносит персонажа; вращение и приближение доступны мышью/касанием/щипком/кнопками. Приближение ограничено поверхностью.
- Обзор кнопкой планеты вращается по двум осям с независимой ориентацией камеры, включая нижнюю грань. Первый вид на поверхности, кнопка, клавиша F и модели рук удалены. Корабельная рубка сохранена.
- Культиватор выдаётся новым и существующим игрокам и отображается в руках. Выбор земли и кнопка инструмента создают новую грядку; она доступна для посадки, созревания, сбора и перезагрузки на гранях куба. До 256 новых грядок на планету.
- Три вида оград: дерево, светлый камень и энергетические перекладины. Установка, поворот, последовательное размещение, сохранение, препятствие для персонажа и демонтаж. До 512 секций на планету. Стоимость 0 для всех тестовых игроков, как и остальные постройки.

## Проверки

- `npm test`: **103 теста, 11 файлов прошли**. Восемь новых проверок покрывают старт и ограничения вступления, одноразовый сбор и настоящий расход материалов, сохранение каждого этапа, совместимость старых игр, новые грядки/семена/урожай на разных гранях, все три вида оград/коллизии/демонтаж, строительство телескопа и отсутствие изменений сохранения при наблюдении.
- Браузерные сценарии **Cubeworks, Journey, Aurora, Flight Deck, Outfit и First Light прошли последовательно** (с отдельным повтором оставшихся сценариев после исправлений и переподключения терминала). Cubeworks проверяет блоки, землю, сохранения, программы, ямы, якоря окружения и переходы граней. Journey проверяет инструменты, блок под ногами, удалённую программу, опыт, движение, фундаменты, трос, ночь, плавных акторов и остановку камеры на рёбрах/углах. Aurora проверяет физические здания, сканы/улучшения/проценты, верфь, паспорт, гусеничную и межпланетную логистику и посадку. Flight Deck проверяет семь окон на 1440×1000, 390×844 и 844×390, управление сразу после постройки и вход в корабль при выбранном гарпуне. Outfit проверяет реальную прокрутку, инвентарь/установку техники и корабля, добычу без меню и удержание удара. First Light проверяет всю цепочку вступления через интерфейс с перезагрузкой после первого растения и в показе системы; сад, посев и три ограды с сохранением; физический телескоп, далёкий неизвестный мир с карты без открытия маршрута/записи мира; свободное вращение и мобильное вступление на 390×844 и 844×390. Отсутствие первого вида на поверхности проверяется явно. Просмотрены изображения вступления, сада, телескопа и системы.
- `npm run test:production`: итоговая сборка прошла проверку подписанного Telegram API, SQLite, `/planets/`, SDK, fullscreen/safe areas, настоящего создания и размещения устройств, полёта/перезагрузки/посадки. Новый профиль проходит все этапы ремонта через авторизованный API до прежних проверок полёта.
- `npm run package:server` / `npm run build`: TypeScript и Vite прошли. Основной JS около 916 КБ / 262 КБ gzip. Предупреждения о размере чанка и аннотациях стороннего Zod остаются; ошибок сборки нет.
- `npm run test:upgrade`: проверены успешное обновление, отказ при повреждённом сохранении, согласованная резервная SQLite-копия, сохранение .env и приложения и автоматический откат. `npm run test:runtime`: итоговый архив установлен только с production-зависимостями; HTML, health и защищённый API работают. Все проверки выполнялись в изолированных временных каталогах с подменой управления сервисом.
