# Little Planets 0.12 New Dawn — проверка 20 октября 2026

База: `9da2529a9717410ce92998e3ab0ad8d70a586ed9`, ветка `little-planets-mvp`. Node.js 24.19.0, Chromium с программным WebGL. Изменения только в `little-planets`.

## Изменения

- Однократный сброс прежних тестовых сохранений по запросу пользователя. Формат 6 получил `generation = 2`. Старые поколения и прототипы начинают настоящий пролог с ПИКО, тремя растениями, повреждённым кораблём и стартовым домом. Старые постройки, земля, машины, запасы, корабли, опыт и открытые маршруты сбрасываются. Нынешнее поколение больше не сбрасывается; будущие неизвестные поколения отвергаются.
- SQLite записывает результат сброса при первом входе. Локальное сохранение записывается сразу при загрузке, до первого действия: повторное открытие вступления не создаёт новый мир. Устаревшая ревизия клиента получает конфликт с актуальным состоянием.
- Родная остаётся 46×46 на грань. На всех шести гранях низкие воксельные террасы 0–1.35 м вместо прежних 0–6.3 м. Среднеквадратичное отклонение высоты на 12 696 клетках: 1.319 → 0.379 м. Общие рёбра остаются ровными. Другие планеты сохраняют прежний рельеф.
- На нерасчищенной Родной 64 лесных дерева вместо 128. После расчистки остаётся половина доступных мест, с округлением вниз. Поля, кусты и папоротники не прореживаются. Декоративные скалы уменьшены; прежнее декоративное святилище на Родной убрано.

## Проверки

- `npm test`: **109 тестов, 12 файлов прошли**. Новые проверки сброса всех систем, сохранения нового задания после перезагрузки, записи SQLite для разных игроков, конфликта старой ревизии, подписанного Telegram API, будущих поколений, высот всех граней и фактического количества деревьев. Проверки больших перепадов рельефа обновлены: Родная намеренно ровнее, исследовательские миры остаются гористыми.
- `npm run test:dawn`: прошёл. В настоящий браузер подставлено старое сохранение с прежней постройкой, машиной, большим запасом ресурсов и опытом. Проверены новое вступление, сброс зданий/машин/опыта/ресурсов, запись поколения до первого нажатия, повторное открытие без нового сброса, полный сбор трёх растений, перезагрузка посреди задания, добыча железа, расход материалов ремонта, первый запуск и сохранённый показ системы. Просмотрены изображения более ровной и разреженной Родной.
- `npm run test:production`: итоговая сборка прошла Telegram API/SQLite, префикс /planets/, SDK, safe areas/fullscreen, устройства, полёт и посадку.
- `npm run test:upgrade`: успешное обновление, отказ при повреждённых данных, резервные копии и автоматический откат прошли в изолированных каталогах. `npm run test:runtime`: архив устанавливается только с production-зависимостями, отдаёт HTML, health и защищённый API.
- TypeScript/Vite и `npm run package:server` прошли. JS около 917 КБ / 262 КБ gzip. Предупреждения стороннего Zod и размера чанка остались; ошибок сборки нет.
