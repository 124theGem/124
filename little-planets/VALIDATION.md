# Cubeworks 0.6 — проверка 19 октября 2026

Среда: Linux x86_64, Node.js 24.19.0, npm 11.9.0, Chromium с программным WebGL. Изменения выполнены только в `little-planets` поверх опубликованного коммита `453ba1494051bc1ceeaee78e1cfcd48dd4b1d6b6` ветки `little-planets-mvp`.

## Пройдено

- `npm ci`: установка по lockfile без отключения TLS/проверок целостности.
- `npm test`: **50 тестов, 6 файлов, все прошли**. Проверены шесть плоских граней, совпадение raycast с положением ног, все 24 направленных перехода через рёбра и непрерывность физической поверхности. Родная — 38×38 клеток на грань; восемь прежних круглых миров удалены.
- Серверные правила добычи: выдача кирки, уничтожение конкретных верхних/боковых блоков, настоящая пустота под сохранённым верхним слоем, материалы блоков, обратная установка с расходованием материала, ограничения расстояния/темпа/ядра, сохранение и восстановление.
- Настоящий цикл сборщика: добыча выбранного ресурса, ровно 24/30 (80%) → движение к складу → выгрузка → продолжение. Проверена остановка программы, ошибочные соединения и закрытые направления.
- Цепочка **склад А → груз дрона → склад Б → 3 дерева + 3 камня → композит → второй дрон → склад Родной**: реальные списания/зачисления, груз сохраняется в полёте, материалы не дублируются. Вторая цепочка превращает 3 композита и 2 кристалла в сплав. Повторный timestamp не дублирует результат.
- Охотники находят и уничтожают живых врагов; противники возвращаются через 30 секунд. Крафт, броня, бой, сад, здания, мебель, интерьер, сканер, события, управляемый полёт и SQLite/CAS/Telegram HMAC проверены регрессионными тестами.
- `npm run test:cubeworks`: **прошёл Chromium**, 1100×800, 390×844 и 844×390. Проверены клавиатура и touch-джойстик, добыча и установка через UI, перезагрузка сохранения, создание устройств, изменение порога, перетаскивание блока, соединение портов и сохранение настоящего исполняемого графа. Проверены отсутствие горизонтального переполнения и ошибок шейдеров/WebGL.
- Отдельные браузерные сцены: яма с полупрозрачными стенками и природой; неподвижные мировые координаты неба, облаков и вихря при ходьбе; изменение гравитации и интерполяция камеры на ребре. Скриншоты создаются в игнорируемом `test-results/cubeworks-*.png`.
- `npm run build` / `npm run package:server`: TypeScript и production-сборка прошли. Предупреждения сборщика относятся к аннотациям стороннего Zod и размеру основного JS (~812 КБ, ~227 КБ gzip); ошибок сборки нет.
- `npm run test:production`: прошёл на итоговой собранной версии: production запрещает локальный вход; проверены подписанная Telegram-авторизация, SDK/safe areas/fullscreen, префикс `/planets/`, создание устройств и сохранение через настоящий API/SQLite, управляемый перелёт, перезагрузка в полёте и посадка.
- `npm run test:upgrade`: успех, повреждённое сохранение и откат после провала health check прошли. Используются настоящая временная SQLite и изолированные заглушки systemd/владельцев/npm; работающий сервер не затрагивается.
- `npm run test:runtime`: готовый архив реально распакован и установлен только с production-зависимостями; проверены HTML, `/api/health` и отказ в доступе к API без Telegram-авторизации.

## Практические границы

Сохранения версий 1–5 начинают новую игру; старая база сохраняется резервным копированием перед обновлением. Машины симулируются во время открытой игры на всех мирах сохранения; непрерывного офлайн-планировщика нет. Персонаж ходит по верхней поверхности: пустоты и навесы геометрически настоящие, но отдельная физика ходьбы внутри горизонтальных тоннелей не реализована. Самые глубокие блоки образуют неразрушимое ядро.

Нативные Telegram-клиенты на физических телефонах и HTTPS на действующем VPS не проверялись. Проект `street-racing`, работающий сервер, Caddy и DNS не изменялись. Исторические браузерные сценарии сфер 0.4/0.5 не являются проверками этой версии; они заменены актуальным `test:cubeworks`.
