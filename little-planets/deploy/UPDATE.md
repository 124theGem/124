# Обновление до Sanctuary 0.5

**Прогресс Odyssey 0.4 сохраняется: формат сохранения остаётся 4.** Старые прототипные форматы 1/2/3, как и прежде, начинают новую игру. Токен бота, `.env`, systemd, Caddy и URL Mini App сохраняются. Скрипт делает резервную копию старого приложения и SQLite перед переключением.

Ожидаемая текущая установка:

- приложение `/opt/little-planets` и закрытый `.env`;
- Node.js 24 в `/opt/little-planets-node`;
- сервис и системный пользователь `little-planets`;
- `HOST=127.0.0.1`, `PORT=8003`;
- `DATABASE_PATH=/var/lib/little-planets/planets.sqlite`.

Скачайте архив репозитория конкретного опубликованного коммита и извлеките `little-planets` во временную папку. От root:

```bash
/opt/little-planets-node/bin/node /ПУТЬ/К/little-planets/deploy/upgrade.mjs /ПУТЬ/К/little-planets
```

Сценарий использует готовый `releases/little-planets-sanctuary-v5.tar.gz`, проверяет SHA-256 и устанавливает production-зависимости по lockfile в новую папку до остановки игры. Пересборка на VPS не нужна.

Затем останавливается только `little-planets`, создаётся согласованная SQLite-копия, проверяется чтение всех сохранений новым кодом. Предыдущее приложение перемещается в `/opt/little-planets-backup-ДАТА/app`, новая папка получает прежний `.env` с правами 600. Прежний сервис запускается и проходит `/api/health`. При провале запуска возвращаются старый код и старая база.

Для сохранений формата 4 новая игра не создаётся: положение персонажа пересчитывается по высоте нового рельефа. Сброс при первом входе относится только к форматам 1/2/3. Сам файл базы не удаляется; внутри сохраняются пользовательские записи текущего формата 4. Резервная копия содержит прежний прогресс. Не удаляйте её до проверки через Telegram.

После установки полностью закройте Mini App и откройте заново. Откройте **☰ → Планеты**: доступны восемь сфер разных биомов и прежние миры. После взлёта управляйте кораблём или включите **Автопилот**. У маяка при скорости ниже 7 м/с нажмите **Посадка**. URL остаётся `https://bot.razdorhouse.ru/planets/`; настройки BotFather менять не нужно.

Проверки разработчика:

```bash
npm run package:server
npm run test:upgrade
npm run test:runtime
```

Тест обновления выполняет сценарий во временных каталогах с настоящей SQLite и HTTP, заменяя systemd, владельцев и npm локальными заглушками. Проверяются успех, повреждённые данные и откат после провала health check. Runtime-тест отдельно реально устанавливает только production-зависимости из пакета и проверяет приложение.

Ручной откат после игры в новой версии требует восстановления и старого кода, и соответствующей старой базы. Новые действия после резервной копии при этом потеряются.
