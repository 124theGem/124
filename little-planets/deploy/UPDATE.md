# Обновление до Little Planets 0.11 First Light

Готовый пакет: `releases/little-planets-firstlight-v11.tar.gz`, рядом SHA-256. Собирать frontend на VPS не требуется. **Прогресс версий 0.6–0.10 (формат 6) сохраняется**: инвентарь, рельеф, программы, машины и базы остаются; добавляются поля сканов, профиля, ангара и производственных буферов. Строительство и крафт в тестовой версии бесплатны для всех игроков; сырьё для переработки расходуется как обычно. Старые задания переработки сохраняют оплаченные входы, результат забирается из выходного буфера гусеничным дроном. Более старые прототипные форматы 1–5 по прежнему правилу начинают новую игру. Прежний файл SQLite остаётся в резервной копии. `.env` и токен бота сохраняются.

Ожидаемая существующая установка:

- `/opt/little-planets`, сервис и системный пользователь `little-planets`;
- Node.js 24+ и npm в `/opt/little-planets-node/bin`;
- `.env` с `HOST=127.0.0.1`, `PORT=8003`, `DATABASE_PATH=/var/lib/little-planets/planets.sqlite` и существующим `BOT_TOKEN`.

Скачайте исходники **опубликованного коммита** ветки `little-planets-mvp`. От root выполните:

```bash
/opt/little-planets-node/bin/node /ПУТЬ/К/little-planets/deploy/upgrade.mjs /ПУТЬ/К/little-planets
```

Сценарий проверяет SHA-256 пакета и существующие настройки, распаковывает новую версию во временный каталог `/opt`, устанавливает production-зависимости по lockfile **до остановки игры**. Затем останавливает только `little-planets`, создаёт согласованную SQLite-копию через SQLite backup API, проверяет чтение сохранений новым кодом и сохраняет прежнее приложение в `/opt/little-planets-backup-ДАТА/app`. Новое приложение получает прежний `.env` с правами 600 и прежнего владельца.

Запускается существующий сервис без изменения unit-файла. Если новая версия не проходит `/api/health`, возвращаются прежнее приложение и соответствующая база. Caddy, DNS, проект street-racing и другие сервисы не меняются. Сценарий не нужно запускать для первоначальной установки.

После обновления полностью закройте Telegram Mini App и откройте заново. Все планеты увеличены примерно на 20%; грань Родной — 46×46 клеток. Сохранения формата 6 переносят координаты и воксельные правки один раз, сохраняя ресурсы, программы и производство.

В автоматизации сверху выберите тип → **Создать в инвентарь**. Затем **Разместить из инвентаря** → **Разместить** → участок → **Установить**. Корабль на верфи также создаётся в инвентарь, в раздел «Корабли»; при размещении устанавливается вместе с площадкой. Предыдущий корабль на заменяемой площадке возвращается в инвентарь. Для полёта нажмите установленный корабль → **Войти в кабину**. Площадка сохраняется, а маяк посадки соответствует её фактическому месту.

Для добычи выберите кирку, нажмите блок и кнопку удара справа; удержание повторяет добычу без контекстного окна.  Миникарты больше нет; звёздная карта остаётся в меню. В горизонтальном режиме «Системы колонии» листаются жестом или колесом.

Не удаляйте резервную копию до проверки игры. Ручной откат после новых игровых действий требует вернуть и старый код, и старую базу, что удалит прогресс после копии. Обновление и автоматический откат проверяются `npm run test:upgrade` в изолированных временных каталогах; настоящий systemd и работающий сервер этот тест не затрагивает.

Вступление с ремонтом корабля запускается для новых игр; существующим игрокам не нужно заново открывать маршруты. Формат сохранений остаётся 6. Культиватор автоматически появляется в инвентаре; грядки, растения и три вида оград сохраняются. Здание телескопа и кнопка «Рассмотреть планету» на карте открывают наблюдение без переноса персонажа. Режим от первого лица на поверхности удалён; обзор планеты теперь свободно вращается по двум осям.
