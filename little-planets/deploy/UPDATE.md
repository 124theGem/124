# Обновление до Little Planets 0.16 Atlas

Готовый пакет: `releases/little-planets-atlas-v16.tar.gz`, рядом SHA-256. Frontend уже собран.

**Прогресс 0.14 и 0.15 сохраняется.** JSON 6 и `generation = 3` остаются прежними. Сохраняются постройки, инвентарь, корабли, опыт, программы, урожай и старые изменения земли. Кирка и гарпун удаляются из инвентаря, выдаётся топор, старый выбранный инструмент заменяется им. Незавершённая поездка по тросу возвращает персонажа к исходной точке и закрывается. Миграция сразу сохраняется при первом чтении. Нового сброса и повторного вступления для завершивших его нет.

Atlas добавляет девять разных корабельных компоновок, настоящее пятиракурсное представление чертежа, отдельные архитектуры зданий, светящиеся окна и ночные фонари. Сохранённые корабли получают геометрию своей платформы, сохраняя имя, компоненты, ливрею, владельца и характеристики.

Предыдущий Outpost добавил промышленный полупрозрачный UI, новые PBR-здания, детализированные корабли, четыре ливреи с регистрацией и именем, сохранение проектов, реальную рубку всех лесных деревьев игроком и сборщиками. Ручное редактирование блоков, кирка и гарпун удалены. Железо в стартовом задании извлекается взаимодействием с обломками метеорита без инструмента.

Строительство бесплатно всем тестовым игрокам; ремонт и производство продолжают расходовать настоящие материалы. Происхождение графических материалов: [ASSETS.md](../ASSETS.md).

## Существующая установка

- приложение `/opt/little-planets`, системный сервис/пользователь `little-planets`;
- Node.js 24+ в `/opt/little-planets-node/bin`;
- `.env`: `DATABASE_PATH=/var/lib/little-planets/planets.sqlite`, `HOST=127.0.0.1`, `PORT=8003`;
- действующий `BOT_TOKEN` остаётся в прежнем `.env`.

Запускайте опубликованный блок обновления из SSH-сессии от root. Он скачивает исходники точного коммита, проверяет SHA-256 готового архива и запускает `deploy/upgrade.mjs`.

## Резервная копия и откат

Upgrader проверяет существующие настройки, распаковывает пакет во временный каталог `/opt` и устанавливает production-зависимости по lockfile до остановки игры. Затем останавливает только `little-planets`, делает согласованную SQLite-копию через SQLite backup API и проверяет сохранения новым кодом. Прежнее приложение перемещается в `/opt/little-planets-backup-ДАТА/app`, рядом сохраняется база. Новый процесс получает прежний `.env` с прежним владельцем и правами 600.

При отказе проверки данных или health-сигнала сценарий восстанавливает старое приложение и нужную копию SQLite, затем запускает прежний сервис. Если обновление прошло, каталог резервной копии остаётся на сервере; его путь выводится в ходе обновления. Системный unit, Caddy, DNS и другие проекты не меняются.

## После обновления

Полностью закройте и заново откройте Mini App, чтобы загрузить новый frontend. В нижней панели будут топор, культиватор, оружие и руки. Для леса выберите топор → дерево → **Рубить дерево**; можно удерживать кнопку топора справа. Несколько ударов срубают дерево, вырубка сохраняется.

На верфи выберите ливрею и имя. **Сохранить проект** сохраняет настройки, **Создать в инвентарь** производит корабль. Установите его из инвентаря вместе с площадкой. Нажмите корабль → **Войти в кабину**; маршрут выбирается отдельно.

## Последующие обновления автоматически

Можно один раз установить [обновляющий скрипт и таймер](GITHUB-AUTOUPDATE.md). VPS будет получать канал проверенных релизов из GitHub по HTTPS примерно раз в две минуты, с теми же резервными копиями и механизмом отката. Первое включение выполняется пользователем через его SSH-сессию. Самостоятельный SSH-доступ Codex для работы таймера не требуется.
