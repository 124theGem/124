# EMBERFALL — Пепел и золото

Первая играбельная глава новой одиночной RPG. Игрок приходит в заброшенную шахту, выполняет поручения Морвина, собирает экипировку, развивает героя и проходит три этажа до последнего хранителя. Стартует сразу в игровом мире.

## Игровые системы

- **Классы.** Рыцарь с мечом и круговой атакой; следопыт с реальными летящими стрелами; маг с огненными снарядами и кольцом огня. Выбор класса — в панели персонажа. В этой версии смена бесплатна и сохраняет весь прогресс.
- **Бой.** Ручные повторные атаки, прицеливание в ближайшую цель, способности с расходом маны и восстановлением, критические удары, защита, рывок с короткой неуязвимостью. Необязательная автоатака включается в настройках. Движение и камера обновляются каждый кадр; враги обходят стены по общей карте путей.
- **Мир.** Три этажа с возрастающей сложностью. На каждом 12 противников, включая хранителя, четыре сундука, три лечебных кристалла, торговец, лестница. Этажи используют одну планировку шахты с различной сложностью и персистентным состоянием. Каменные стены имеют коллизию; декоративные бочки и ящики проходимы.
- **Добыча.** Монеты и экипировка действительно выпадают после боя и из сундуков. Они подбираются при приближении. Пять редкостей: обычная, необычная, редкая, эпическая и легендарная. В полном рюкзаке предмет остаётся на земле. Убитые противники, сундуки и ещё не подобранные предметы сохраняются; повторная выдача блокируется.
- **Экипировка.** Оружие, броня, кольцо, сапоги. Выбор предмета показывает его параметры и разницу с надетым. Экипировка изменяет реальные характеристики. Заменённый предмет возвращается в рюкзак. Вместимость — 40 вещей.
- **Развитие.** Опыт и уровни усиливают героя. Каждый новый уровень даёт очко талантов: сила, здоровье или средоточие. Средоточие повышает критический шанс и снижает затраты маны. При повышении уровня здоровье и мана восстанавливаются.
- **Задания.** Уничтожить шесть противников, открыть три сундука, победить хранителя. Награды выдаются из журнала заданий ровно один раз. Трекер показывает ближайшее невыполненное поручение.
- **Торговля.** Морвин продаёт зелья за 35 монет и улучшает оружие: +3 атаки, увеличение уровня предмета и растущая цена заточки. Ненужные вещи продаются из рюкзака.
- **Поражение и финал.** Возрождение возвращает ко входу с потерей 10% монет; уровни и вещи остаются. Победа над хранителем открывает лестницу. На третьем этаже лестница показывает финал; после него можно продолжить исследование.

## Управление

| Действие | Компьютер |
| --- | --- |
| Движение | WASD / стрелки |
| Путь по подземелью | Щелчок по полу |
| Подойти и атаковать | Щелчок по противнику |
| Атаковать повторно | Удерживать пробел |
| Способность | Q |
| Рывок | Shift |
| Открыть / торговать / спуститься | E или F |
| Выпить зелье | R |
| Рюкзак / задания / атлас | I / J / M |
| Пауза / закрыть окно | Esc |

На телефоне: джойстик слева, кнопки справа, рюкзак открывается отдельной кнопкой. В портретной ориентации кнопки занимают два ряда; в горизонтальной — один. Боковая панель превращается в прокручиваемое окно. Пока оно открыто, игра приостановлена.

## Сохранение и ограничения

Сохранение — `localStorage`, ключ `emberfall.rpg.save.v1`. Оно записывается каждые пять секунд, после важных действий, при уходе со страницы и потере фокуса. Старые игры используют другие ключи и серверные таблицы; их прогресс не удаляется. В настройках можно скачать JSON-копию. Повреждённый JSON сохраняется под отдельным ключом перед созданием нового профиля. При запрете/переполнении localStorage игра предупреждает, что сохранение недоступно.

RPG работает без API и регистрации. Поэтому профиль не синхронизируется между телефоном и ПК, данные доверены локальному устройству. Здесь нет рейтинга с призами, платных предметов, PvP, гильдий и мультиплеера. Старые серверные системы RIFT RAID остаются доступны только своему режиму; RPG не обращается к их валюте и платежам.

## Графика и производительность

Оригинальные кэшируемые пиксельные спрайты и предварительно отрисованная карта Canvas 2D, сортировка объектов по глубине, коллизии, мягкое сопровождение камеры, тёплые источники света, тени, световые столбы редкой добычи, плавающие числа урона, частицы и анимации. DPR ограничен двумя, частицы — 220. `prefers-reduced-motion` отключает фоновые колебания и переходы интерфейса. Большие библиотеки архивных 3D-игр не входят в стартовый RPG-чанк.

Материалы и лицензии перечислены в [ASSETS.md](ASSETS.md). Это оригинальная интерпретация визуального направления референса, не точная копия чужой графики.

## Запуск и поставка

```bash
cd little-planets
npm ci
npm run dev:client
```

`http://localhost:5174`. Сборка: `npm run build`. Боевой сервер остаётся прежним: `npm start`, порт из окружения. На существующей установке приложение откроется по прежнему HTTPS-адресу после установки архива; корневой URL выбирает RPG, `?mode=raid` — архивный шутер.

`npm run package:server` создаёт `releases/little-planets-server-v0190.tar.gz`, SHA-256 и `deploy/artifact.json`. Архив включает собранный фронтенд, прежний backend, shared-модули и lockfile. `.env`, пользовательская SQLite и `node_modules` в него не входят. Существующие настройки и база должны оставаться на сервере. Автоканал `deploy/channel.json` не изменён.

## Проверки

- `npm run test:rpg`: модель боя, реальная экипировка, пути ко всем важным объектам, защита от повторной добычи, сохранение, зелья, торговец, кузнец, таланты, смерть/возрождение, полное прохождение трёх этажей.
- `npm run test:rpg-browser`: production-сборка через настоящий backend и префикс `/planets/`; компьютер 1440×960, телефон 390×844 и 844×390. Движение/остановка, клавиатура/джойстик, экипировка, перезагрузка, окна, бой, сундук, торговец, магические снаряды, отсутствие JavaScript-ошибок и горизонтального переполнения. Позиции в отдельных сценариях задаются тестовыми фикстурами, действия выполняются настоящими игровыми обработчиками.
- `npm test`: общий набор модельных и серверных тестов, включая архивные игры.

Браузерная проверка выполняется в Chromium с эмуляцией размеров/касания, не на физическом телефоне и не внутри установленного клиента Telegram. Скриншоты — [docs/screenshots/emberfall](docs/screenshots/emberfall).
