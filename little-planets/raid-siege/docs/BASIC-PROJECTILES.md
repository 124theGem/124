# Обычные выстрелы — 0.8.1

Пользовательский пакет `cartoon_projectile_vfx_pack.zip` подключён к реальным обычным снарядам героев.

| Герой | Анимация из пакета |
| --- | --- |
| Друид | Зелёный сгусток `toxic_slime_projectile_flight.png` |
| Маг огня | `fire_projectile_flight.png` |
| Маг холода | `ice_projectile_flight_6frames.png` |
| Арбалетчик | Розовая стрела `neon_arrow_flight_6frames.png` |
| Лучник, шаман | `neon_lightning_projectile_flight.png` |
| Жрец, бард | `pink_magic_projectile_flight.png` |
| Некромант | Зелёный сгусток `toxic_slime_projectile_flight.png` |

Каждый вариант проигрывает шесть кадров при 18 FPS до попадания или окончания полёта. Изображение следует за реальным снарядом; направление поворота учитывает проекцию игровой камеры. Головка совпадает с положением снаряда в симуляции, а хвост остаётся позади. Время подготовки скрывает спрайт до вылета. Навыки, ульты, мины и ближние удары сохраняют свои отдельные визуалы. Боезапас, скорость, дальность и урон не менялись.

Исходные PNG 2172×724 сохранены без изменения пикселей. У них неравномерные ширины кадров и большие прозрачные поля: реальные границы, высота и положение головки размечены в `projectileFrames.json`. Рендерер выбирает эти прямоугольники по UV, без деления полосы на шесть одинаковых ячеек. Небольшой отступ в половину пикселя предотвращает захват соседнего кадра. Файлы переиспользуются на GPU через общие текстуры; после исчезновения снаряда удаляются только его меш, материал и ссылка на текстуру.

Целевая проверка в игровой сцене 844×390: все девять назначений, шесть кадров, восемь направлений, совпадение головки с координатой снаряда, отсутствие эффекта до вылета, исключение навыков и мин. После 144 завершений полёта число мешей, материалов и текстур возвращается к исходному; ошибок JavaScript нет. Полный набор тестов не запускался.
