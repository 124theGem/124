# RAID & SIEGE · 0.7

Яркий мультяшный прототип фэнтезийной 3D Action RPG для браузера и Telegram Mini Apps.
TypeScript · Vite · Babylon.js · Telegram Mini Apps SDK. Backend и реальные сетевые матчи не нужны.

## Запуск

Требуется Node.js 22.12+; в `.nvmrc` и `.node-version` закреплён проверенный Node 24.19.0.

```bash
cd /workspace/124
npm ci
npm run dev
```

Для production: `npm run build`, затем разместите **всё содержимое `dist/`**, включая `models/` и `fonts/`, на HTTPS-хостинге. `npm run preview` позволяет проверить собранную версию. Vite dev server не является production-сервером.

В облачной среде с недоступным домашним каталогом используйте `npm_config_cache=/workspace/.npm-cache` перед командами npm. Секреты и переменные приложения не требуются.

## Что реализовано

- Три локальных режима: рейд с четырьмя группами врагов и боссом в трёх фазах; осада с последовательными A → B → C; царь горы до 300 очков.
- 16 выбираемых классов, по три активных способности: два навыка и ультимейт. Все 48 имеют игровые эффекты, стоимость, кулдаун и правила выбора цели.
- Один локальный игрок, два настраиваемых союзных бота; в PvP — три бота-противника. Жёсткий лимит — три **героя** на команду; временные призывы ограничены отдельно.
- Урон, броня, магическое сопротивление, снаряды, стены, лечение, щиты, бафы, скрытность, провокация, яд, горение, контроль и уклонение.
- Ролевой ИИ с задержкой реакции, обходом препятствий, лечением и уклонением от предупреждений босса.
- Два независимых джойстика: движение и направление атаки/навыков/ультимейта, линия прицела и область попадания, выстрел при отпускании. Полный экран и горизонтальная ориентация, safe areas, пауза при потере видимости или повороте.
- Скелетные GLB-модели KayKit CC0, 22 используемых клипа на модель, смешивание анимаций, классовые аксессуары, эффекты и синтезированный боевой звук.
- 30 предметов пяти редкостей, сравнение и экипировка, опыт и уровни 1–30, золото и улучшения, локальное сохранение. В PvP снаряжение и улучшения нормализованы.
- Dev-меню: F10 или кнопка F10 на телефоне. Команды отладки удаляются из production-кода.

## Управление

| Действие                  | ПК                | Телефон                                        |
| ------------------------- | ----------------- | ---------------------------------------------- |
| Движение                  | WASD / стрелки    | Левый джойстик                                 |
| Обычная атака             | Удерживать пробел | Перетянуть для прицела, отпустить для выстрела |
| Навыки, включая ультимейт | 1, 2, 3, 4        | Перетянуть и отпустить; нажатие — автоприцел   |
| Уклонение                 | Shift             | Кнопка рывка                                   |
| Пауза                     | Escape            | Кнопка справа сверху                           |
| Отладка (только dev)      | F10               | Небольшая кнопка F10                           |

Короткое нажатие выбирает цель автоматически в пределах дальности и прямой видимости. При перетягивании выстрел следует заданному направлению, без доводки к ближайшей цели. Ультимейт заряжается со временем, от урона и лечения. В рейде двигайтесь на север; красные зоны предупреждают об атаках босса. В PvP герои возрождаются волнами с краткой защитой.

## Проверки

```bash
npm run typecheck
npm test
npm run build
npm run test:browser
```

Браузерные проверки используют установленный `/usr/bin/chromium`. На другой машине задайте `CHROMIUM_PATH` либо установите Chromium и укажите его путь. Тесты запускают Vite автоматически, если сервер ещё не работает. Симуляционные тесты работают в Node без DOM, Babylon.js и Telegram.

## Границы прототипа

Это рабочая игровая основа, а не завершённая коммерческая игра. Пять базовых моделей используются для вариантов 15 классов; оружие, цвета и аксессуары различаются, но 15 полностью уникальных профессиональных моделей ещё не созданы. Окружение стилизованное. Звук процедурный. Полировка анимаций, баланс, реальные Android/iOS WebView, проверка Telegram-клиентов и FPS на телефонах требуют дальнейшей работы. Целевые 30/60 FPS не заявлены как достигнутые.

Нет авторизации, матчмейкинга, сетевого backend, античита или облачного сохранения. Локальный профиль допускает изменение игроком. Игра опубликована в канал существующей установки @LittlePlanets_bot. Адрес, сведения о выпуске и порядок запуска — в [TELEGRAM.md](docs/TELEGRAM.md). Факт применения выпуска на VPS проверяется отдельно от публикации канала.
