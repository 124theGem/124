Пакет VFX для скилла танка: прыжок в точку + AOE-взрыв + кольцо щитов.

Состав:
1) tank_jump_impact_explosion_atlas.png
   - Спрайт-лист большого взрыва в точке приземления.
   - Рекомендуемая длительность проигрывания: 1 секунда.
   - Предполагаемая сетка: 6 колонок x 5 строк = 30 кадров.
   - Рекомендованный FPS: 30.

2) tank_jump_shield_ring_loop_atlas.png
   - Спрайт-лист кольца щитов по большому радиусу.
   - Использовать после взрыва как отдельный эффект.
   - Рекомендуемая длительность отображения: 3 секунды.
   - Предполагаемая сетка: 5 колонок x 5 строк = 25 кадров.
   - Рекомендованный режим: растянуть/проиграть за 3 секунды или зациклить при необходимости.

Рекомендуемый порядок в игре:
1. В момент приземления запустить tank_jump_impact_explosion_atlas.png.
2. После завершения взрыва сразу показать tank_jump_shield_ring_loop_atlas.png по тому же центру.
3. Держать щиты 3 секунды.

Примечание:
- Оба ассета подготовлены как 2D VFX-спрайт-листы для интеграции в игру.
- При необходимости можно затем упаковать их в WebP/атлас вашего движка.
