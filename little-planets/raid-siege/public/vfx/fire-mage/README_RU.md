# Огненный маг — три игровых VFX для Babylon.js

Пакет содержит **настоящие RGBA-спрайт-атласы с последовательными кадрами** (не картинку-концепт) и исходный TypeScript-модуль. Отдельного демо или интерфейса нет.

## Скиллы

| Навык | Визуальные фазы | Рекомендуемые параметры |
|---|---|---|
| **1. Кометный огненный шар** | движущийся огненный снаряд с хвостом → ударная вспышка при попадании | скорость 11 ед./с, попадание 0,66 с |
| **2. Огненное кольцо** | расширяющийся огненный обруч вокруг мага + искры | радиус 4,5 м; 1,2 с |
| **3. Метеорит** | предупреждение зоны → летящий метеорит → мощный АОЕ-взрыв | предупреждение 0,70 с, падение 0,90 с, взрыв 1,2 с, радиус 5,5 м |

> Система VFX **не наносит урон**. Она передаёт событие `onImpact` / `onDamage` в вашу существующую боевую систему. Хитбоксы, реальные цели, сопротивления, урон и кулдауны рассчитываются игрой.

## Структура

- `textures/*.png` — прозрачные спрайт-листы 256 px/кадр; главное для игры.
- `previews/*.gif` — краткие анимированные примеры на тёмном фоне.
- `previews/*.webp` — покадровые прозрачные анимации, пригодны для предпросмотра.
- `previews/contact_sheet.jpg` — все этапы эффекта на одном изображении.
- `src/fire_mage_vfx.ts` — функция запуска каждого из трёх эффектов в Babylon.js.
- `generate_assets.py` — исходный генератор текстур, позволяет менять форму, цвет и продолжительность.
- `manifest.json` — формат и скорость атласов.

## Подключение к Telegram Mini App / Babylon.js

1. Скопировать **содержимое папки `textures`** в `public/assets/vfx/fire-mage/` проекта на Vite.
2. Скопировать `src/fire_mage_vfx.ts` в папку исходников игры.
3. Импортировать функции:

```ts
import { castCometFireball, castFireNova, castMeteor } from './fire_mage_vfx';

// Комета. Когда долетела, игра выполняет проверку попадания / урон.
castCometFireball(scene, mage.position.add(new Vector3(0, 1.2, 0)), enemy.position, {
  speed: 11,
  onImpact: (point) => combat.fireballHit(point),
});

// Кольцевой огонь вокруг персонажа.
castFireNova(scene, mage.position, {
  radius: 4.5,
  onDamage: (center, radius) => combat.damageInRadius(center, radius),
});

// Метеорит в указанную точку. Зона видна до падения.
castMeteor(scene, selectedGroundPoint, {
  radius: 5.5,
  onImpact: (center, radius) => combat.damageInRadius(center, radius),
});
```

`combat` — ваш существующий объект боевой системы, **в этом пакете не содержится**. Подставьте свои методы, чтобы не создавать конфликтов с текущей игрой.

## Важные ограничения

- Для корректного масштабирования радиуса в Babylon.js рекомендуется игровая единица = метр (или измените радиусы).
- Размер картинок и количество кадров не равны хитбоксам: зону урона задаёт симуляция.
- Эффекты — стилизованные 2D-проекции, которые показываются на billboard- и ground-planes в 3D-мире.
- Видимость спрайтов и сортировку прозрачных объектов нужно проверить в вашей конкретной сцене. Исходный код здесь не тестировался в реальном Telegram WebView.
- На слабых телефонах снижайте разрешение атласов, число частиц и интенсивность вспышек.

Авторские игровые VFX, созданные процедурно для этого запроса. Не использованы чужие графические ассеты.
