# Prismatic Descent — Arcane Beam VFX v2

Это **новая оригинальная анимация** по визуальному описанию и таймингу загруженного видео ActionVFX. Ни один кадр оригинального ролика, его логотип или водяной знак не включён в файлы.

## Что изменено относительно v1

- В оригинальном видео `Animated_Fantasy_Beam_001_9153_2K.webm` основная энергия держится около 2,5 секунд, а не исчезает через одну.
- Теперь **белое яркое ядро луча**, **рваные тёмно-синие и фиолетовые края**, **тонкие овальные энергетические кольца**, **голубые плоские ударные разряды на земле**.
- 3 самостоятельные фазы с большим количеством повторно используемых кадров: активация → поддержание → затухание.
- Нет лишних персонажей, фонов и водяных знаков. PNG имеет альфа-канал.

## Тайминг

| Этап | Время | Кадры | Атлас |
|---|---:|---:|---|
| Появление | 0,50 с | 12 | `arcane_intro_*.png` |
| Основной луч | 2,33 с | 16 кадров в цикле × 3,5 цикла | `arcane_loop_*.png` |
| Затухание | 0,33 с | 8 | `arcane_outro_*.png` |
| **Всего** | **3,17 с** | 76 отображаемых кадров при 24 FPS | |

Отдельные атласы создают более приятную загрузку, чем один гигантский спрайт-лист на 76 кадров.

## Разрешение

- `optimized/`: **512×512 на кадр**. Максимальный атлас 2048×2048. Рекомендуется для Telegram Mini App.
- `hd/`: **768×768 на кадр**. Максимальный атлас 3072×3072. Для высоких настроек качества.
- Все атласы PNG RGBA. Прозрачный фон.

### Установка Babylon.js

1. Скопируйте папки `optimized/` и `hd/` в `/public/assets/vfx/arcane_beam_v2/`.
2. Скопируйте `arcaneBeamVfx.ts` в свой TypeScript-проект.
3. Один раз при загрузке сцены:

```ts
const beamFx = createArcaneBeamVfx(scene, '/assets/vfx/arcane_beam_v2', 'mobile');
```

4. Когда нужна способность:

```ts
beamFx.play(targetPosition, {
  width: 6,
  height: 6,
  onImpact: (point) => {
    // ВАША игровая логика: урон, эффект состояния, контроль, и т. п.
  },
});
```

5. При выгрузке сцены: `beamFx.dispose()`.

**Важно:** это VFX, а не логика урона; прямой визуальный эффект только показывает попадание. В реальной игре следует привязать `onImpact` к игровому серверу или локальной симуляции. Для корректного положения точку `targetPosition` задавайте по поверхности земли.

### Ограничения

- Нарисованная процедурная 2D-анимация с билбордингом, **не** 3D-симуляция ActionVFX и не покадровая копия исходного ролика.
- Непосредственно в проекте пользователя на Babylon.js не запускалась: по месту могут потребоваться настройка масштаба, качества и смешивания.
- На мобильных 512px — хороший старт. HD использовать только после теста памяти GPU.

В `previews/` есть анимированная GIF-проверка и отдельные ключевые кадры.
