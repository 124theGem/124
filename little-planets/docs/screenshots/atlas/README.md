## Осмотр игровых моделей

- [Девять корабельных компоновок](fleet.png): все используют одни и те же выбранные корпус/крылья/двигатель/модуль, поэтому видны различия самих платформ. Жёлтая окраска выбрана для Kestrel.
- Жилой сервисный дом: [день](house-day.png), [ночь](house-night.png).
- Склад: [день](warehouse-day.png), [ночь](warehouse-night.png).
- Переработка: [день](refinery-day.png), [ночь](refinery-night.png).
- Сканер: [день](scanner-day.png), [ночь](scanner-night.png).

Осмотр снят отдельным тестовым стендом с настоящими фабриками, материалами и функцией ночных фонарей. Сетка флота составлена программой непосредственно из девяти рендеров. Это стенд игровых моделей, не HUD колонии и не концепт-арт.

Chromium / SwiftShader. Размеры устройств — CSS viewport, плотность пикселей ограничена тестами. Физические телефоны и производительность их GPU не проверялись. Ретушь, генерация изображений и встроенные пиксели референсов не использовались.
