# Outpost 0.15 — реальные снимки рендера

Верфь снята в работающей игре: [компьютер 1440×1000](outpost-shipyard-desktop.png), [телефон 390×844](outpost-shipyard-portrait.png), [телефон 844×390](outpost-shipyard-landscape.png). Размеры — CSS viewport; плотность пикселей ограничена тестом.

[Корабль](outpost-ship.png) и [штаб](outpost-headquarters.png) сняты отдельным стендом с настоящими игровыми фабриками моделей и материалами. Это осмотр моделей, не игровой HUD.

Chromium / SwiftShader; физические телефоны и производительность их GPU не проверялись. Ретушь и генерация изображений не применялись.
