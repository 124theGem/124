# Little Planets

Играбельный MVP для Telegram Mini App и локального браузера: объёмные voxel-острова, космонавт, маленький сад и путешествия между тремя мирами. Все игровые модели собраны из настоящей 3D-геометрии. Референс используется как направление, это самостоятельная упрощённая графика прототипа.

## Быстрый запуск на Windows

Установите **Node.js 24 LTS**. Используется встроенный `node:sqlite`, отдельно устанавливать SQLite, Python или компилятор C++ не требуется.

В PowerShell или терминале в папке проекта:

```powershell
cd little-planets
npm ci
npm run dev
```

Откройте `http://localhost:5174/`. Команда запускает Vite на 5174 и новый backend на 8003. Если вы уже находитесь в `little-planets`, первый `cd` пропустите. Telegram-токен и `.env` для обычной локальной игры не нужны. Локальный режим хранит мир в `localStorage` именно этого браузера; удаление данных сайта удалит локальный прогресс.

На телефоне в той же Wi-Fi-сети откройте `http://IP_КОМПЬЮТЕРА:5174/`. IPv4 компьютера можно узнать через `ipconfig`. Разрешите Node.js в брандмауэре Windows для частной сети. HTTPS нужен для настоящего Telegram Mini App, локальный тест на телефоне работает по HTTP. Физический запуск Windows и реальных телефонов в облачной проверке не выполнялся.

## Что делать в игре

- **WASD / стрелки** или экранный джойстик — движение относительно камеры. Края, вода, дома, грядки и активные источники ресурсов блокируют проход.
- Нажмите объект: космонавт найдёт путь к нему. Контекстная карточка предложит действие. Кнопка **Посадить** сама выбирает подходящую грядку: сначала готовый урожай, затем пустую.
- Выберите одно из трёх семян текущего биома. Обычное растение растёт **15 секунд**, редкое — **30**. Есть три разные визуальные стадии. Сбор даёт **3 урожая и 2 семени**, освобождая грядку.
- Источник ресурса даёт **3 единицы**, восстанавливается через **20 секунд**. Восстановление и рост продолжаются после закрытия игры, по сохранённым временным отметкам.
- **Построить** включает сетку и полупрозрачную модель. Выберите домик, теплицу или склад, нажмите подходящее место, при желании поверните и подтвердите. Красная модель означает занятое место. Стартовых ресурсов хватает на домик.
- **Галактика** ведёт космонавта к кораблю. Выберите Листорию, Мицелию или Пирос. Перелёт занимает около 3 секунд без перезагрузки страницы. Сад, постройки и ресурсы остаются на своих планетах, а инвентарь общий.
- **◇** переключает исследование и обзор планеты. Перетаскивание свободной области вращает камеру, колесо мыши и щипок двух пальцев меняют масштаб.
- В **⚙** есть полноэкранный режим и переключение качества. Telegram 8+ получает запрос нативного fullscreen; старые клиенты используют expanded viewport. Системные безопасные области учитываются.

Листория — зелёная поверхность, деревья, дом, цветы и водопад. Мицелия — фиолетовая почва, светящиеся грибы и голубые кристаллы. Пирос — тёмные камни, огненные растения, термокристаллы и потоки лавы.

## Проверки

```powershell
npm test
npm run build
```

При запущенном `npm run dev`:

```powershell
npm run test:browser
```

После сборки `npm run test:production` запускает временный backend и браузер: проверяет production-вход, HTTP-маршрут `/planets/`, настоящий локальный SDK, серверные сохранения и безопасные области Telegram. Токен в этом тесте — искусственная фикстура, реальный бот не нужен.

Браузерный тест по умолчанию использует `/usr/bin/chromium` в облачной среде. На Windows укажите путь к установленному Chrome/Chromium:

```powershell
$env:CHROMIUM_PATH = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
npm run test:browser
```

`GAME_URL` меняет адрес тестового Vite. Сценарий рассчитан на development-режим: production не предоставляет локальный вход. Результаты и ограничения — [VALIDATION.md](VALIDATION.md).

## Telegram и сервер

Локальный режим включён только в Vite development-сборке при отсутствии Telegram `initData`. В production он отключён. Обычный посетитель production-сайта получает приглашение открыть игру через бота.

В Telegram сервер проверяет HMAC-SHA-256 подпись `initData`, время авторизации и ID пользователя из **проверенных** данных. `initDataUnsafe`, `userId` из тела запроса и тестовые логины не используются для доступа. Вход действует час; после истечения откройте Mini App заново.

SQLite хранит по одному миру на проверенного пользователя. Клиент отправляет действия, а не заменяет инвентарь произвольным JSON. Посадка, сбор, строительство и перелёт проверяются общей игровой моделью на сервере; время берётся с сервера. Ревизия и транзакция защищают от потери прогресса при параллельных действиях. При конфликте другая вкладка должна повторить действие после синхронизации. Это MVP, полноценная защита от читов в движении не реализована.

Размещение на отдельном маршруте с HTTPS, переменные окружения, systemd и BotFather описаны в [deploy/README.md](deploy/README.md). Автоматически изменять ваш действующий сервер проект не пытается.

## Структура

| Папка | Назначение |
| --- | --- |
| `shared` | Каталог биомов, рецепты, схемы действий, рост, коллизии и правила мира |
| `src/world` | Фабрики 3D-моделей, персонаж, планеты и группировка статической геометрии |
| `src/game` | Игровой цикл, управление, выбор объектов, строительство и перелёт |
| `src/platform` | Telegram fullscreen/safe areas, localStorage и API сохранений |
| `server` | Fastify, проверка Telegram-подписи и SQLite |
| `tests` | Правила игры, сохранения, авторизация, API и браузерный игровой цикл |

В памяти находится только активная планета. Одинаковые блоки, материалы и геометрия переиспользуются; статические объекты объединяются в InstancedMesh. Один источник света отбрасывает тени, карта 1024². Разрешение ограничено 1.5× и снижается при устойчиво медленных кадрах; в настройках можно отключить тени.

## Границы MVP

Домик, теплица и склад размещаются, сохраняются и показывают назначение; интерьеров и специальных производственных бонусов пока нет. Урожай хранится в инвентаре, торговли и крафта нет. Боковые грани декоративные. Нет мультиплеера, боёв, доната, питомцев и бесконечной галактики. Музыка и звуки в это ТЗ не включены.

Цели 30/60 FPS не подтверждены измерениями реальных смартфонов. Нативные Android/iOS WebView и реальный Telegram-токен в облачной среде не использовались. Локальная графика и ввод проверяются Chromium, а серверная авторизация — подписанными тестовыми данными. Для настоящего Telegram-запуска нужны ваш `BOT_TOKEN` в защищённом `.env` сервера и публичный HTTPS.
