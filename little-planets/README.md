# Little Planets — Frontiers 0.3

Telegram Mini App с объёмными voxel-мирами, строительством базы, садом, интерьером дома, крафтом, экипировкой, боем и исследованием круглой планеты.

## Локальный запуск

Нужны Node.js 24 LTS и npm; SQLite встроена в Node.js.

```bash
cd little-planets
npm ci
npm run dev
```

Frontend — `http://localhost:5174/`, backend — 8003. В development без Telegram доступна локальная игра без токена. Для телефона в той же сети используйте `http://IP_КОМПЬЮТЕРА:5174/`. Production принимает только подписанный Telegram initData и требует HTTPS.

**Это тестовая версия с новым миром.** По просьбе пользователя прогресс между версиями не переносится. Локальный ключ — `little-planets-v3`; старые серверные сохранения версий 1/2 при первом чтении заменяются новой игрой. Токен бота и настройки сервера сохраняются. Перед обновлением скрипт создаёт резервную копию прежней базы.

## Компактный интерфейс

Мини-карта без рамки находится справа сверху. В ней видны персонаж, источники, постройки, животные, метеорит и живые противники. Количество имеющихся ресурсов показывается в рюкзаке, верхняя ресурсная панель убрана. В рецептах остаётся требуемая стоимость.

Кнопка **☰** слева снизу раскрывает рюкзак, крафт, сад, строительство, планеты и настройки. Меню сворачивается после выбора действия. Все обычные окна закрываются крестиком; у размещения мебели/зданий крестик закреплён сверху, у больших окон — вне прокручиваемого содержимого. Окно также закрывается нажатием фона или Escape.

WASD / стрелки или джойстик — движение. Нажмите объект для подхода и действия. Закрытая карточка не открывается повторно сама. Перетаскивание вращает камеру, колесо / щипок меняет масштаб. Кнопка 🌐 и мини-карта переключают обзор и следящую камеру. В горизонтальном режиме действует компактная раскладка с учётом безопасных областей Telegram.

## Миры и сканер

- **Родная, 38×38** — главная база. Здесь строятся главный дом, жилые дома, теплицы, склады и лаборатории.
- **Листория, Мицелия, Пирос, 17×17** — мирные исследовательские планеты с добычей ресурсов.
- **Ферра, 23×23**, и **Нокс, 25×25** — открытые враждебные миры с шестью противниками каждый.
- **Орбис** — большая сферическая планета с обхватом 120 м, радиусом около 19.1 м и поверхностью около 4584 м². По ней можно непрерывно пройти экватор, оба полюса и обратную сторону. Это отдельная геодезическая модель движения с радиальным направлением «вверх», поворотом персонажа и переносом камеры без скачка на шве. Скорость — 6 м/с. Карта показывает развёртку 120×60. Строительство и грядки на тестовой сфере отключены; источники собираются, корабль позволяет вернуться.
- **24 экспедиционных мира** создаются по предустановленным процедурным семенам, с разными названиями, биомами, размером и враждебностью. Они скрыты до обнаружения. Это конечный пул прототипа.

**Планеты** ведёт к кораблю и открывает атлас. Поле поиска фильтрует открытые миры по названию; **Найти случайную планету** открывает ещё один ранее неизвестный мир. Сканер работает у корабля, находки сохраняются. Посетить ещё не открытый экспедиционный мир сервер не разрешает.

## Крафт, оружие и броня

Мастерская содержит крупные иллюстрированные карточки с изображениями самих 3D-предметов, категориями и выбранным рецептом. Иллюстрации создаются локально как затенённые векторные сцены, без внешнего сервиса изображений. Все созданные вещи попадают в ячейки рюкзака.

| Предмет            | Действие                                                    |
| ------------------ | ----------------------------------------------------------- |
| Клинок разведчика  | 14 урона, дистанция 2.7 м, задержка 520 мс                  |
| Кристальное копьё  | 23 урона, дистанция 3.8 м, задержка 700 мс                  |
| Импульсный бластер | 20 урона, дистанция 8 м, задержка 650 мс; нужна лаборатория |
| Броня разведчика   | Поглощает 2 урона каждого удара                             |
| Броня стража       | Поглощает 5 урона каждого удара                             |
| Кристальная эгида  | Поглощает 8 урона каждого удара; нужна лаборатория          |

В **Рюкзаке** выберите созданное оружие/броню и нажмите **Надеть**. Доступны по одному слоту оружия и брони, кнопки снятия и отметки надетых вещей. Экипировка видна на 3D-персонаже и действительно влияет на бой. Предметы при надевании не исчезают из рюкзака.

На враждебных планетах есть панцирные хищники, дроны и кристальные стражи. Они патрулируют, замечают персонажа, сближаются и атакуют. Нажмите врага либо кнопку **Атака** / пробел; если нужно, космонавт подойдёт ближе. Удар, дистанция, задержка, здоровье и награда проверяются сервером. Без оружия доступны слабые удары рукой.

Победа приносит 5 единиц местного ресурса и 2 кристалла, один раз за противника. Побеждённые враги сохраняются и не возрождаются в этой версии. При поражении персонаж возвращается на Родную с полным здоровьем и сохранённой экипировкой. Офлайн-время не превращается в часы непрерывных атак; бой симулируется ограниченными шагами подключённой игры. При возвращении на Родную здоровье восстанавливается. Меню на опасной планете не останавливает противников.

## Погода и звук

Периодически возникают метеориты, сильный ветер, дождь, гроза и ураган. Есть падающие капли, движущиеся облака, молнии со вспышкой и громом, вращающийся вихрь с частицами. Погода следует общей сохранённой временной шкале; на сфере эффекты ориентируются по местной вертикали. Метеорит после падения даёт 4 кристалла и 6 камня при однократном исследовании. Животные гуляют по обычным планетам.

Добавлена оригинальная синтезированная фоновая музыка: мелодия, бас и мягкие аккорды. Эффекты сопровождают шаги, посадку, сбор, строительство, крафт, удары, урон, победу, полёт и погоду. Всё генерируется Web Audio локально, звуковые файлы и сетевые музыкальные сервисы не нужны.

Звук активируется первым нажатием. Кнопка **♫** переключает общий звук. В настройках отдельно включаются музыка и эффекты, регулируется громкость; предпочтения сохраняются. В скрытой вкладке AudioContext приостанавливается.

## База, сад и главный дом

На Родной размещаются гражданские здания; на остальных плоских мирах — только добывающие модули. Выберите ресурс и поставьте модуль не дальше пяти клеток от соответствующего источника. Модуль копит 3 ресурса каждые 20 секунд, включая офлайн-время. Буфер — 40 плюс 40 за каждый домашний склад. Для биомодуля и продвинутых рецептов нужна лаборатория. Готовый комплект из рюкзака используется первым, иначе строительство списывает ресурсы.

Сад: три растения на биом, обычные растут 15 секунд, редкие — 30, с тремя стадиями. Сбор даёт 3 плода и 2 семени; ещё одно семя создаётся из двух плодов. Ручной сбор источника даёт 3 ресурса с восстановлением через 20 секунд.

Нажмите главный дом, подойдите, выберите **Войти**. Откроется отдельная комната. Создайте в мастерской стул, стол, кровать, диван, шкаф, ковёр или камин и разместите через **Мебель**. Мебель можно вернуть в рюкзак и переставить, проход к двери защищён от застройки. Нажмите дверь и **Выйти**. Комната и обстановка сохраняются в пределах этой версии.

## Проверки и размещение

```bash
npm test
npm run build
npm run test:browser    # npm run dev должен быть запущен
npm run test:frontiers  # экипировка, сканер, бой и обход сферы
npm run test:events     # все пять видов событий
npm run test:production
npm run package:server
npm run test:upgrade
npm run test:runtime
```

Для короткой отдельной проверки сферы: `FRONTIERS_CASE=sphere npm run test:frontiers` (Bash). Браузерные сценарии используют системный Chromium, путь меняется через `CHROMIUM_PATH`; `GAME_URL` задаёт development-адрес. На программном WebGL запускать сценарии последовательно. Результаты — [VALIDATION.md](VALIDATION.md).

Telegram 8+ получает нативный запрос fullscreen, старые клиенты — expanded viewport. Production не предоставляет локальный вход: сервер проверяет HMAC initData, время и Telegram ID. Действия проверяются сервером, SQLite и ревизии защищают от перезаписи другой вкладкой. Полноценной защиты от читов в движении в прототипе нет.

Установка: [deploy/README.md](deploy/README.md). Обновление работающего сервера: [deploy/UPDATE.md](deploy/UPDATE.md). URL остаётся `https://bot.razdorhouse.ru/planets/`. Токен хранится только в защищённом серверном `.env`.

## Границы прототипа

В памяти одна активная сцена. Геометрия и материалы переиспользуются, статические объекты и фауна группируются в InstancedMesh. Сферические ресурсы также объединены в общие пакеты, а направление камеры переносится по поверхности.

Нет мультиплеера, торговли, доната, бесконечной генерации миров и приручения животных. Жилые дома и теплицы пока декоративные. Сфера тестовая: ровная поверхность с декоративными камнями/деревьями, без строительства и симуляции рельефных препятствий. Бой поддерживает базовые типы врагов, без сложных боссов и боеприпасов. Производительность и нативный Telegram требуют проверки на реальных телефонах.
