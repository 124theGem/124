# Little Planets — Outpost 0.15

Telegram Mini App: колония на шести гранях кубических планет, фермерство, заготовка ресурсов, программируемые машины, производственные цепочки и управляемые космические корабли.

## Outpost

Общий интерфейс оформлен как промышленная консоль: полупрозрачный графит, тонкие светлые линии, спокойные бирюзовые/янтарные акценты и контурные пиктограммы. Окна и верфь поддерживают компьютер, телефон и горизонтальную ориентацию; разделы и настройки прокручиваются.

Корабли используют общую PBR-модель в верфи, инвентаре, на площадке и в полёте: секционная обшивка, фаски, механические опоры, сервисный вход, рампа, сопла, остекление и оборудование. Новая архитектура колонии включает отдельные панели, несущий каркас, проёмы, окна, рампы, лестницы и инженерные системы. У верфи есть открытый сборочный зал, кран и манипуляторы; у переработки — резервуары и трубы; у склада — грузовые секции; у сканера — тарелка и антенны. Бурильная станция растёт до пяти уровней, сканер — до десяти.

Оригинальные PBR-карты имеют разрешение 1024×1024, ливреи — 2048×512. Используются отдельные albedo, roughness, normal и AO. Это процедурные игровые модели и текстуры, не фотосканированные ассеты. Источники и лицензии: [ASSETS.md](ASSETS.md).

## Верфь и проекты

Нажмите установленную верфь. В центре — настоящий 3D-просмотр с вращением, масштабом и сбросом ракурса. Настройки корпуса, крыльев, платформы, двигателя, модуля, материала, цвета и ливреи сразу меняют модель. Скорость, груз и броня учитывают выбранные компоненты.

Четыре ливреи: Aurora Expedition, Helix Freight, Polar Rescue, Orion Defence. В них есть оригинальные логотипы вымышленных корпораций, полосы, технические надписи, имя и регистрационный номер корабля, следы эксплуатации. Регистрация стабильна для имени/класса/платформы.

**Сохранить проект** записывает конфигурацию в текущее сохранение. До 20 именованных проектов; повторная запись того же имени обновляет проект. **Загрузить проект** восстанавливает настройки. **Создать в инвентарь** производит настоящий корабль; выберите его в инвентаре и разместите с площадкой. Замена площадки возвращает припаркованный корабль в инвентарь. Нажмите установленный корабль → **Войти в кабину**. Маршрут выбирается отдельно на карте. Полёт ведётся из рубки, при подходе к планете появляется посадка.

## Инструменты и лес

Кирка, гарпун, поездки по тросу, ручное разрушение земли и установка отдельных блоков удалены из управления, интерфейса и серверных действий. Воксельная земля, готовые здания, техника, грядки и ограды остаются. Межпланетные путешествия выполняются на корабле.

Топор выдаётся автоматически новым и существующим игрокам. Выберите его на нижней панели (клавиша 1), нажмите дерево и **Рубить дерево** или удерживайте кнопку топора справа. Все лесные деревья на всех шести гранях доступны для заготовки. Крупным деревьям нужно 3–6 ударов; они дают 6–15 древесины в зависимости от размера. Маленьким ресурсным деревьям — 2 удара, выход 4 древесины. Незавершённая рубка и вырубка сохраняются. Срубленные деревья не восстанавливаются через 20 секунд.

Сборщики используют те же деревья и конечные запасы древесины. Если грузовой отсек не вмещает весь выход, остаток сохраняется у источника до следующего сбора. Запас не дублируется при совместной работе игрока и нескольких роботов. Прочие небольшие источники ресурсов сохраняют восстановление через 20 секунд.

Культиватор позволяет делать грядки: выберите инструмент, нажмите землю, затем кнопку инструмента. Нажмите грядку для посадки. Сохраняются урожай, новые грядки и деревянные/каменные/энергетические ограды.

## Вступление и сохранения

Новая игра начинается с чёрного экрана и появления дымящегося повреждённого корабля. ПИКО автоматически выдаёт задание: три подсвеченных растения → извлечь железо из обломков метеорита → восстановить двигатель → запустить корабль. Кирка для метеорита не требуется. Ремонт расходует 3 биоволокна и 3 железа даже в бесплатном тестовом режиме. После запуска камера отдаляется через созвездия; в каталоге 1206 миров.

**Обновление с 0.14 не сбрасывает прогресс.** Формат остаётся 6, `WORLD_GENERATION = 3`. Старые кирка/гарпун убираются из инвентаря, выбранный старый инструмент заменяется топором. Незавершённая поездка по тросу безопасно возвращает персонажа к сохранённой исходной точке. Сохраняются постройки, программы, корабли, опыт, грядки и прежние изменения земли. Миграция сразу записывается в SQLite или локальное сохранение и не повторяет вступление. Историческое правило для поколений до 3, введённое в 0.14 по отдельному запросу, остаётся прежним.

Родная — 46×46 клеток на грань, пологий естественный ландшафт и 64 лесных дерева до вырубки/расчистки. Светлый камень, густая зелень, поля и воксельные террасы сохранены. Ветер, пыльца и светлячки привязаны к миру. Есть три сохраняемых уровня качества, LOD деталей, ограничение разрешения и частиц для телефонов.

## Колония и автоматизация

Строительство, улучшения, сборка кораблей и машин бесплатны для всех игроков тестовой версии. Материалы переработки и ремонта расходуются по правилам. Строительство автоматически выравнивает основание и расчищает растительность.

В автоматизации выберите тип → **Создать в инвентарь** → размещение из инвентаря → участок → **Установить**. Сборщики, охотники, грузовые дроны и гусеничные логисты управляются настоящими графами программ. Состояние графов сохраняется, включая удаление всех блоков.

Склады содержат реальные ресурсы. Грузовые маршруты связывают планеты, гусеничные логисты перевозят сырьё со склада в переработку и возвращают продукцию. В каталоге 30 видов сырья и многоступенчатые рецепты из двух компонентов. Офлайн-планировщика нет: симуляция идёт, пока игра открыта; оплаченные задания и перелёты учитывают сохранённое время.

Сканер открывает окружение и состав миров; телескоп и карта позволяют рассматривать планеты, не перемещая персонажа. Обзор планеты свободно вращается. Есть день/ночь, опыт, навыки, респаун противников, охотники и профиль с зонами интереса/космическим паспортом. Миникарта и первое лицо на поверхности отсутствуют; рубка корабля сохраняется.

## Разработка

Node.js 24+ для встроенной SQLite, npm, Chromium для браузерных проверок:

```bash
cd little-planets
npm ci
npm run dev
```

Vite — порт 5174, API — 8003. Локальная разработка не требует Telegram-токена. Production принимает подписанный Telegram initData. Реальный токен хранится только в серверном `.env`.

```bash
npm test
npm run build
npm run test:browser
npm run test:production
npm run package:server
npm run test:upgrade
npm run test:runtime
```

`test:browser` запускает актуальные сценарии Flight Deck, First Light, Horizon и Outpost при работающем `npm run dev`. Они проверяют окна, постройки, вступление, 3D-конструктор, ливреи, проекты, корабли и настоящую рубку леса. Старые сценарии добычи отдельных блоков и гарпуна относятся к прежним версиям и в текущий набор не входят. Геометрия старого рельефа и полезные регрессии продолжают проверяться unit-тестами.

Браузер — `/usr/bin/chromium`, переопределение через `CHROMIUM_PATH`. На программном WebGL запускайте браузеры последовательно; не меняйте исходники и не выполняйте сборку во время прогона.

Готовый пакет: `releases/little-planets-outpost-v15.tar.gz` и SHA-256. [Обновление](deploy/UPDATE.md), [проверки](VALIDATION.md). Настройки сервера, DNS, Caddy и street-racing не изменяются.
