# RAID & SIEGE · размещение 0.20.0

Главный адрес Mini App бота @LittlePlanets_bot теперь предназначен для новой 3D Action RPG. См. [RAID-SIEGE.md](RAID-SIEGE.md). Серверный API, SQLite и сохранения прежних игр сохранены. Их входы: `?mode=emberfall`, `?mode=raid`, `?mode=colony`.

```bash
npm ci
npm run build
npm test
node scripts/package-server.mjs
npm run test:upgrade
node --import tsx tests/raid-siege-production.mjs
```

Новая игра имеет отдельные исходники, lockfile и проверки в `raid-siege/`. Для отдельной разработки: `cd raid-siege && npm ci && npm run dev`. Публикация использует существующий HTTPS-маршрут `/planets/` и проверяемый канал автообновления. Установка на VPS должна подтверждаться публичным ответом или журналом updater.

Ниже сохранена документация предыдущего выпуска.

# EMBERFALL · Пепел и золото · 0.19.0

Новая одиночная action RPG для браузера и Telegram Mini App. Вид сверху, оригинальная пиксельная графика, каменные подземелья, деревянные мостки, факелы и сокровища. Главная страница теперь открывает Emberfall.

- Три класса: рыцарь, следопыт и маг; ближний бой, стрелы, огненные снаряды и способности.
- Три связанных этажа, скелеты, слизни и хранители; сундуки, кристаллы, торговец и кузнечное улучшение.
- Уровни, опыт, таланты, задания, пять редкостей экипировки и сравнение характеристик.
- Плавное управление с клавиатуры, щелчком или экранным джойстиком.
- Автосохранение на этом устройстве, экспорт JSON; отдельное хранилище от прежних игр.

[Описание и управление](EMBERFALL.md) · [Скриншоты](docs/screenshots/emberfall) · [Происхождение графики](ASSETS.md)

```bash
cd little-planets
npm ci
npm run dev:client
```

Откройте `http://localhost:5174`. Node 24+. Для одиночной игры не нужны бот-токен, Telegram-вход и сервер API. Для публикации как Telegram Mini App используйте HTTPS-адрес существующей установки и прежний Telegram SDK.

```bash
npm run build
npm run test:rpg
npm run test:rpg-browser
npm test
npm run package:server
```

Ветка новой игры — `emberfall-rpg`. Серверный архив — `releases/little-planets-server-v0190.tar.gz`, SHA-256 рядом. Архив совместим с существующим запуском `server/index.ts`, портом 8003 и прежним окружением. Никаких изменений серверных настроек, DNS, Caddy или street-racing не требуется.

Версия 0.19.0 продвинута в канал автоматического обновления `little-planets-mvp`, релиз 22. Канал ссылается на проверенный пакет из коммита `a68cf92b611e245cba25b8dcee169db5e33805e4`. Подключённый VPS проверяет канал примерно раз в две минуты; установщик сохраняет резервную копию приложения и SQLite и выполняет откат при ошибке. Сам по себе push исходников без продвижения канала обновление не запускает. Проверка установки на VPS: `journalctl -u little-planets-pull.service -n 40 --no-pager`.

Это первая завершённая глава одиночной RPG, не MMO: нет сетевой экономики, PvP, гильдий, серверного RPG-профиля и покупок. Сохранение привязано к браузеру/устройству. Эти ограничения не маскируются фиктивными кнопками.
