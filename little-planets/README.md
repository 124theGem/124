# Little Planets — Colony 0.2

Игра для Telegram Mini App: четыре объёмных voxel-планеты, космонавт, сад, добыча, строительство базы и обустройство дома. Все игровые объекты собраны из 3D-геометрии.

## Запуск для разработки

Нужны Node.js 24 LTS и npm. Используется встроенный `node:sqlite`; устанавливать отдельную SQLite не нужно.

```bash
cd little-planets
npm ci
npm run dev
```

Frontend работает на `http://localhost:5174/`, backend — на 8003. В development без Telegram доступны локальные сохранения в браузере. Токен бота для этого режима не нужен. На телефоне той же сети откройте `http://IP_КОМПЬЮТЕРА:5174/`, разрешив Node.js в локальном брандмауэре. Production требует подписанный Telegram `initData` и публичный HTTPS.

## Миры и строительство

- **Родная — 38×38**: примерно пятикратная площадь обычной планеты 17×17. Здесь находится главный дом; можно строить жилые дома, склады, теплицы и лаборатории.
- **Листория, Мицелия, Пирос — 17×17**: только добывающие модули. Обычные здания базы здесь недоступны и в интерфейсе, и на сервере.
- Буровой модуль добывает минералы, биомодуль — древесину или споры. Выберите ресурс и поставьте модуль не дальше пяти клеток от соответствующего источника. Биомодуль требует домашнюю лабораторию.
- Модуль накапливает **3 ресурса каждые 20 секунд**, в том числе после закрытия игры. Базовая ёмкость каждого модуля — 40; каждый домашний склад добавляет ещё 40. Подойдите к модулю и заберите накопленное.
- Кнопка **Строить** включает сетку и предпросмотр. Нажмите свободное место, при желании поверните объект, подтвердите. Готовый комплект из рюкзака расходуется первым; при его отсутствии строительство списывает ресурсы рецепта.
- Теплица и жилой дом пока декоративные. Склад и лаборатория имеют указанные игровые эффекты.

## Управление и взаимодействия

WASD / стрелки или джойстик перемещают космонавта относительно камеры. Нажмите грядку, ресурс, дом или корабль: персонаж найдёт путь, затем появится карточка действия. Закрытые карточки сами повторно не открываются. Кнопка **Сад** помогает выбрать ближайшую грядку, затем показывает такое же действие.

Нажмите **🌐** или мини-карту, чтобы переключить обзор и следящую камеру. Перетаскивание вращает мир, колесо мыши / щипок меняет масштаб. Мини-карта показывает здания, источники, грядки, животных, персонажа и упавший метеорит.

Рюкзак содержит ячейки со значками, количеством, фильтрами и описанием выбранного предмета. В разделе **Крафт** есть рецепты всех зданий, модулей, мебели и семян. Созданные предметы попадают в рюкзак; их можно разместить кнопкой предмета.

## Сад, животные и события

Для каждого биома доступны три растения; на Родной выращиваются растения Листории. Рост — 15 секунд для обычных и 30 для редких растений, с тремя видимыми стадиями. Урожай даёт **3 плода и 2 семени**. Ещё одно семя можно изготовить из двух плодов. Ручной сбор источника даёт **3 ресурса**, восстановление — 20 секунд.

По планетам гуляют кролики, светящиеся местные животные и панцирные ящерицы. Периодически падает метеорит или начинается сильный ветер с пролетающими облаками. Место и задержка событий зависят от сохранённого начала жизни мира; сервер и клиент видят одно событие. Упавший метеорит можно исследовать один раз: **4 кристалла и 6 камня**. События чередуются, между ними есть тихие промежутки.

## Главный дом

На Родной нажмите главный дом, дождитесь подхода и выберите **Войти**. Откроется отдельная комната. Через **Крафт → Мебель** создайте стулья, стол, кровать, диван, шкаф, ковёр или камин. Для камина нужна лаборатория. **Мебель** включает размещение внутри комнаты. Проход у двери защищён от застройки, предметы нельзя накладывать друг на друга. Нажмите мебель, чтобы вернуть её в рюкзак и переставить. Ковёр не мешает ходить.

Нажмите дверь и **Выйти**, чтобы вернуться к дому. Обстановка сохраняется отдельно для каждого главного дома, в том числе после закрытия игры внутри.

## Полёты и Telegram

Кнопка **Полёт** ведёт к кораблю. Доступны все четыре мира; инвентарь общий, посадки и постройки сохраняются на каждой планете. Корабль поднимается вертикально с дымом, камера на время взлёта зафиксирована; горизонтального перемещения корабля нет.

Telegram 8+ получает запрос нативного fullscreen, старые клиенты — expanded viewport. Учитываются безопасные области устройства и Telegram. В настройках есть повторный запрос fullscreen и экономное качество. Интерфейс имеет отдельную компактную раскладку для горизонтального экрана.

Публичный вход: `https://bot.razdorhouse.ru/planets/`, через настроенную кнопку бота. Настройки сервера — [deploy/README.md](deploy/README.md), обновление работающей версии — [deploy/UPDATE.md](deploy/UPDATE.md).

## Сохранения и обновление

SQLite хранит мир каждого пользователя, определённого серверной проверкой Telegram HMAC. Клиент отправляет действия, сервер проверяет ресурсы, рецепты, биом, расстояние, коллизии и время. Ревизии и транзакции защищают от перезаписи параллельной вкладкой. Полноценной защиты от читов в движении в прототипе нет.

Сохранения версии 1 автоматически переводятся в версию 2: инвентарь, посевы, истощённые источники и текущая планета сохраняются. Построенные игроком гражданские здания переносятся на свободные места Родной. Старые бесплатные стартовые домики заменяет главный дом Родной. Если места под перенос не хватит, здания возвращаются готовыми комплектами в рюкзак. Сервер записывает результат миграции при чтении сохранения. Локальный ключ `little-planets-v1` оставлен для совместимости; версия внутри данных — 2.

## Проверки

```bash
npm test
npm run build
npm run test:browser     # при запущенном npm run dev
npm run test:production # после сборки, поднимает временный backend
npm run package:server  # сборка архива для обновления
npm run test:upgrade    # архив должен существовать
node --import tsx tests/events-browser.mjs # видимые события и сбор метеорита
node tests/runtime.mjs # установка пакета с production-зависимостями
```

Браузерные проверки используют `/usr/bin/chromium`; для другого пути задайте `CHROMIUM_PATH`. `GAME_URL` меняет адрес development-приложения. Браузерный сценарий не работает как локальный вход в production. Подробности и ограничения — [VALIDATION.md](VALIDATION.md).

## Структура и границы прототипа

`shared` содержит каталог и серверные правила, `src/world` — модели, поверхности, интерьер, животных и атмосферу, `src/game` — управление и игровой цикл, `src/ui` — интерфейс, `server` — авторизацию и SQLite.

В памяти находится одна сцена. Статические модели и животные используют InstancedMesh, общую геометрию и материалы; внутри больших островов нет невидимых поштучных каменных столбов. Разрешение автоматически снижается при устойчиво медленных кадрах. Цели FPS на реальных телефонах не измерялись.

Нет мультиплеера, торговли, боёв, доната, приручения животных и бесконечной галактики. Боковые грани островов декоративные. Музыка в эту игру не добавлена. Проверки настоящего Android/iOS Telegram и публичного HTTPS выполняются на вашем сервере; облачные тесты используют Chromium и подписанные тестовые данные.
