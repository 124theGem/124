# COASTLINE — Ночной район / Night City v2

Играемый прототип одиночных 2.5D-гонок: TypeScript, Three.js, Vite. Ночной город со светящимися окнами, вывесками, фонарями, фарами и неоном. Красное заднеприводное купе, аркадное сцепление с настоящим боковым движением и ортографическая камера. Без внешних моделей, графических текстур, серверной части и React.

Night City v2: обычные повороты проходят цепко, короткий ручник инициирует управляемый занос. Добавлена стабилизация курса и помощь при восстановлении сцепления. Это собственная настройка в духе аркадных уличных гонок, а не копия закрытой физики NFS Underground. Для установленной игры на `bot.razdorhouse.ru/racing/` подготовлен [скрипт обновления](deploy/update-game.sh).

## Запуск

Требуется Node.js 22.12+ (в облачной среде проверен Node.js 24).

```bash
cd /workspace/124/street-racing
npm install
npm run dev
```

Откройте адрес, который напечатает Vite. Для смартфона на той же сети используйте сетевой адрес компьютера. Облачный доступ зависит от способа проброса портов вашей платформы. Для переустановки строго по lockfile используйте `npm ci`. Кэш npm хранится в игнорируемой `.npm-cache/`, поэтому запись в домашний каталог не требуется.

```bash
npm run build       # TypeScript и production-сборка в dist/
npm test            # автоматические проверки физики и игровой логики
npm run preview     # просмотр production-сборки
```

Игра сразу открывает трассу. Никаких ключей, сервисов или переменных окружения не нужно.

## Управление

| Клавиши | Действие |
| --- | --- |
| W / ↑ | Газ; при движении назад сначала торможение |
| S / ↓ | Тормоз; около остановки включается задний ход |
| A, D / ←, → | Плавный поворот руля |
| Space | Ручник задней оси |
| R | Вернуться на старт; обнулить текущую попытку круга |
| C | Переключить две ортографические камеры |
| Escape / P | Пауза |

При открытии в Telegram 8.0+ игра запрашивает нативный полноэкранный режим, расширяет панель и отключает вертикальное сворачивание свайпом. HUD учитывает безопасные области ОС и Telegram. Старые клиенты используют расширенный режим. Кнопка с четырьмя уголками повторяет запрос; в обычном браузере она включает/выключает Fullscreen API по нажатию. Сам клиент Telegram может отказать в полноэкранном режиме.

Telegram bridge поставляется локально в `public/vendor/` вместе с MIT-лицензией, поэтому игре не нужно загружать SDK с внешнего CDN. Авторизация и Telegram API для данных не используются.

На телефоне — кнопки руля слева, газ, тормоз и ручник справа. Pointer Events и захват указателя позволяют держать несколько кнопок одновременно. Уход со страницы или потеря фокуса сбрасывают ввод и ставят игру на паузу; продолжение — кнопкой «Поехали». Кнопка `?` показывает подсказки.

Для дрифта наберите скорость, поверните, кратко нажмите ручник, отпустите его и контррулите в сторону скольжения. Постоянное удержание ручника тормозит машину и может привести к развороту. Следите за индикатором угла; газ и короткие коррекции руля помогают удержать занос.

## Физическая модель

`src/physics/CarPhysics.ts` — динамическая велосипедная модель двух осей. Единицы: метры, секунды, килограммы, радианы, ньютоны. Все настройки машины находятся в `src/vehicles/CarConfig.ts`: масса 1250 кг, база 2,6 м, задний привод, ограничение около 180 км/ч, предельный угол руля 32°.

- Хранятся продольная и боковая скорости, положение, курс и угловая скорость. Вектор движения независим от направления кузова.
- Скольжение осей рассчитывается из локальных скоростей и yaw rate. Боковые силы плавно насыщаются через `tanh`; суммарная продольная и боковая сила каждой оси ограничена кругом трения.
- Тяга ограничена силой, мощностью и максимальной скоростью. Работают аэродинамическое сопротивление, сопротивление качению и распределение торможения между осями.
- Перенос нагрузки зависит от продольного ускорения и высоты центра масс. Ручник плавно снижает сцепление задних шин, после отпускания оно восстанавливается. Избыток тяги уменьшает доступную боковую силу задней оси.
- Угол руля на скорости ограничен доступным боковым ускорением. Ограниченная помощь моментом относительно вертикальной оси стабилизирует курс и возвращает кузов к направлению движения после заноса. Боковая скорость и положение при этом продолжают рассчитываться физически.
- Низкие скорости регуляризованы, чтобы исключить деление на ноль. Силы интегрируются в мировой системе координат, чтобы вращение локальной системы не добавляло энергию.
- Физика работает с фиксированным шагом 1/60 с через аккумулятор. После долгого зависания обрабатывается максимум 0,25 с за кадр; скрытая вкладка ставится на паузу.
- Асфальт, обочина и трава имеют разные коэффициенты сцепления. Форма машины для столкновений — капсула из трёх окружностей. Контакты с обеими сторонами дороги разрешаются коррекцией проникновения и импульсами с учётом момента инерции, потери энергии и трения.

Дым, следы шин и очки включаются от реального скольжения. Стоящая машина, езда вне асфальта и разворот почти поперёк/против движения не дают очков дрифта. Для зачёта круга требуется последовательно пройти три сектора и пересечь старт вперёд. Лучшее время сохраняется локально, если браузер разрешает localStorage.

## Графика и структура

`src/tracks/CoastalTrack.ts` создаёт замкнутый Catmull–Rom-сплайн. Все полосы дороги, разметка, поребрики и барьеры следуют его форме. `src/vehicles/Car.ts` — отдельная заменяемая модель купе с поворотом и вращением колёс. `src/game/Camera.ts` — камера с постоянной мировой ориентацией, плавным слежением, упреждением и отдалением на скорости.

Здания, окна, фонари, барьеры, поребрики, световые пятна и разметка используют InstancedMesh. Уличное освещение приближённо рисуется световыми пятнами; реальные динамические фары используют один SpotLight. Дым и искры ограничены пулом 128 частиц; следы — кольцевым буфером 1500 сегментов. Pixel ratio ограничен 1,6, тень — одной картой 1024² возле машины. Геометрия и ресурсы освобождаются при закрытии страницы.

Параметр `?debug=1` показывает FPS и открывает только чтение диагностики `window.__coastline.snapshot()`. Он используется браузерной проверкой; обычный запуск не открывает этот интерфейс.

## Проверка в настоящем браузере

При запущенном `npm run dev`:

```bash
npm run test:browser
npm run test:telegram
```

Проверка использует системный Chromium (`/usr/bin/chromium`). При другом пути задайте `CHROMIUM_PATH`; другой адрес запущенной игры задаётся через `GAME_URL`. Скрипт проверяет 3D-рендер, клавиатуру, физическое скольжение, восстановление сцепления, торможение, инерцию, возврат на старт, переключение камеры, паузу, потерю фокуса, три одновременных касания и адаптацию портрет/альбом. Скриншоты сохраняются в игнорируемую `test-results/`.

Для этой проверки требуется именно Vite dev server: проверка столкновений импортирует исходные модули. Фактические результаты и границы проверки описаны в [VALIDATION.md](VALIDATION.md).

Автоматические тесты проверяют разгон 0–100, максимальную скорость, торможение и инерцию, задний ход, круг трения, боковое скольжение, восстановление после контрруления, различия покрытий, длительную устойчивость численного расчёта, одинаковый результат при 30/60/144 render FPS, ограничение catch-up, столкновения, секторы круга и очки дрифта.

## Ограничения прототипа

Это упрощённая плоская аркадная физика без подвески и вертикальных прыжков. Столкновения рассчитываются для ограждений; здания и фонари — декорации за ними. У шин нет отдельной симуляции температуры, износа и деформации. Время круга использует секторы дискретизированной трассы, точность финиша ограничена физическим шагом и шагом дискретизации.

Автоматическая мобильная проверка эмулирует касания в Chromium, а не настоящий телефон или Telegram WebView. Целевые 60 FPS на ПК и 30 FPS на бюджетных телефонах не подтверждены аппаратными измерениями. В облачном тесте применяется программный WebGL; его FPS не характеризует производительность реального GPU. Для настройки ощущения дрифта требуется дополнительный игровой тест человеком. Звук, повреждения, Telegram API и мультиплеер в этот этап не входят.
