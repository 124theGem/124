# Характеристики автомобиля без пересборки

В исходниках: [`public/car-config.json`](public/car-config.json). При `npm run build` файл копируется в `dist/car-config.json`, отдельно от JavaScript. Игра запрашивает его перед созданием машины при каждом открытии, с отключённым кэшем запроса. Уже открытая игра сохраняет настройки до следующей загрузки страницы.

На вашем сервере после установки v3:

```bash
nano /var/www/coastline-racing/car-config.json
```

Измените числа, сохраните (`Ctrl+O`, Enter), выйдите (`Ctrl+X`), полностью закройте Mini App и откройте заново. Запускать npm, пересобирать проект и перезагружать Caddy не нужно. Сам файл можно проверить по адресу `https://bot.razdorhouse.ru/racing/car-config.json`.

Файл хранится вне папок выпусков. `deploy/update-game.sh` создаёт его только при первой установке функции и затем сохраняет ваши значения. Каждый выпуск ссылается на этот общий файл. Смена выпуска и откат не заменяют настройки. Новые параметры, отсутствующие в вашем файле, берутся из базовых значений текущей версии игры.

## Основные настройки

| Параметр | Сейчас | Что меняет |
| --- | ---: | --- |
| `maxSteerDegrees` | 36 | Предельный угол передних колёс, градусы (10–55) |
| `steeringRate` | 6.5 | Скорость перекладки руля, рад/с (0.5–15) |
| `asphaltGrip` | 2.6 | Сцепление на асфальте (0.8–4); влияет на допустимый поворот на скорости |
| `corneringMargin` | 0.95 | Доля сцепления, используемая ограничителем руля (0.4–1.25) |
| `maxSpeedKmh` | 180 | Ограничение скорости вперёд, км/ч (30–360) |
| `engineForce` | 6900 | Сила тяги, Н (500–22000); разгон с малой скорости |
| `powerKw` | 145 | Мощность, кВт (20–600); разгон на скорости |
| `mass` | 1250 | Масса, кг (500–4000) |
| `brakeForce` | 14000 | Сила торможения, Н (1000–35000) |
| `handbrakeForce` | 5600 | Торможение задней оси ручником, Н (0–15000) |
| `handbrakeGrip` | 0.42 | Доля заднего сцепления при ручнике (0.2–0.95); меньше — легче занос |
| `gripRecovery` | 1.4 | Возврат сцепления после ручника, 1/с (0.2–10) |
| `stabilityAssist` | 14 | Сила помощи выравниванию курса (0–25) |
| `driftStabilityAssist` | 10 | Помощь выравниванию с ручником (0–25) |
| `recoveryAlignment` | 6 | Выравнивание кузова по движению после ручника (0–12) |

Для более резкого отклика сначала попробуйте `maxSteerDegrees: 40` и `steeringRate: 8`. На высокой скорости угол дополнительно ограничивается сцеплением, поэтому для тесного поворота там влияет и `asphaltGrip`. Меняйте по одному параметру и проверяйте ощущения. Очень сильные значения могут ухудшить устойчивость даже в допустимом диапазоне.

## Остальные параметры

Все величины без явной единицы в названии используют СИ: метры, секунды, килограммы, ньютоны, радианы.

- `inertia` — момент инерции вокруг вертикальной оси, кг·м²; `cgHeight` — высота центра масс.
- `wheelbase`, `frontAxle`, `rearAxle` — база и расстояния от центра масс до осей. Требуется `wheelbase = frontAxle + rearAxle`.
- `length`, `width` — размеры физической капсулы столкновений, `wheelRadius` — радиус колёс. Длина должна быть больше базы минимум на 0.3 м. Кузов — фиксированная модель купе; эти параметры не заменяют его моделирование.
- `reverseForce`, `reverseMaxSpeedKmh` — тяга заднего хода и ограничение его скорости.
- `airDrag`, `rolling` — коэффициент аэродинамического сопротивления и сила сопротивления качению.
- `frontStiffness`, `rearStiffness` — боковая жёсткость осей, Н/рад.
- `grassGrip`, `shoulderGrip` — сцепление травы и обочины; `restitution` — упругость контакта с барьером.
- `driftSteeringMultiplier` — увеличение разрешённого руля с ручником; `minimumSteer` — минимальный лимит угла на скорости, рад.
- `maxAssistAcceleration` — ограничение помощи вращению, рад/с²; `maxDriftYawRate` — целевая скорость вращения с ручником, рад/с.

JSON не поддерживает комментарии: подсказки размещены в `_comment` и `_help`. Поля с `_` игнорируются. Можно оставить только нужные параметры — остальные получат базовые значения. Неизвестные названия, строки вместо чисел, недопустимые диапазоны и несогласованная база отклоняют весь набор. При ошибке файла/HTTP или загрузке дольше четырёх секунд игра использует базовую настройку и показывает предупреждение. Подробности также видны в консоли браузера.

Шаг симуляции `fixedStep` остаётся внутренним параметром и через JSON не меняется. Значения по умолчанию и допустимые диапазоны находятся в `src/vehicles/CarConfig.ts` и `src/vehicles/LoadCarConfig.ts`.
