# Размещение на razdorhouse.ru через Caddy

Подготовлено для присланного Caddyfile: основной домен `razdorhouse.ru` в нём ещё не объявлен; существующие сайты `bot`, `aicc` и подключаемый сайт сохраняются. Игра будет доступна по `https://razdorhouse.ru/racing/`, корень домена перенаправляется туда.

DNS основного домена должен указывать на этот сервер. Caddy сам получает HTTPS-сертификат. Нужен активный systemd-сервис `caddy` с конфигом `/etc/caddy/Caddyfile`; скрипт проверяет это перед изменениями.

1. Скачайте предоставленный `coastline-server.tar.gz` на компьютер.
2. Из терминала компьютера загрузите его на сервер, используя тот же IP, что и для SSH:

   ```bash
   scp coastline-server.tar.gz root@IP_СЕРВЕРА:/tmp/
   ```

3. В SSH-терминале сервера выполните:

   ```bash
   mkdir -p /tmp/coastline-upload
   tar -xzf /tmp/coastline-server.tar.gz -C /tmp/coastline-upload
   bash /tmp/coastline-upload/deploy-coastline.sh
   ```

Скрипт проверяет SHA-256 архива, сохраняет резервные копии в `/etc/caddy/coastline-backup.*`, распаковывает отдельный выпуск в `/var/www/coastline-racing/releases/`, создаёт `/etc/caddy/sites/coastline-racing.caddy` и добавляет одну строку его импорта. Перед перезагрузкой выполняется `caddy validate`; при ошибке проверки или перезагрузки восстанавливаются предыдущие файлы и ссылка на выпуск. Чужой существующий блок `razdorhouse.ru` или файл назначения останавливает установку.

Успех подтверждается строкой `READY: https://razdorhouse.ru/racing/` после проверки HTML и JavaScript по публичному HTTPS. Если конфиг загружен, но сертификат/DNS ещё не готовы, скрипт завершится кодом 2 с подсказкой диагностики. Готовность сайта в этом случае ещё не подтверждена.

В BotFather используйте `/setmenubutton`, выберите бота, задайте адрес `https://razdorhouse.ru/racing/` и подпись «Играть».

Локально проверены синтаксис Bash, конфигурация настоящим Caddy 2.10.2, первая и повторная установка, откат при сбое проверки/перезагрузки, защита существующего домена. Системный сервис и публичный HTTPS в этих локальных сценариях имитировались. На сервере пользователя скрипт ещё не выполнялся.
