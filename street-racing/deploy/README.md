# Игра на существующем HTTPS-домене бота

Актуальный адрес игры: **https://bot.razdorhouse.ru/racing/**.

DNS, показанный владельцем: основной сайт `razdorhouse.ru` находится на `95.163.244.138`, а `bot`, `aicc`, `gas` направлены на VPS `201.34.135.216`. Эти записи сохраняются. Для игры используется существующий HTTPS-домен бота.

## Для уже установленной сборки

Игра распакована предыдущим установщиком в `/var/www/coastline-racing/current`. Запустите `use-bot-domain.sh` на VPS от root:

```bash
bash /tmp/coastline-use-bot.sh
```

Сам скрипт находится в этой папке репозитория; его можно загрузить с GitHub в `/tmp/coastline-use-bot.sh`. Используйте ссылку на конкретный коммит и опубликованную контрольную сумму из инструкции в чате.

Скрипт:

- Проверяет наличие установленной игры и активность Caddy.
- Добавляет `/racing/` в существующий блок `bot.razdorhouse.ru`, сохраняя backend `127.0.0.1:8000` для остальных путей.
- Удаляет только строку импорта `/etc/caddy/sites/coastline-racing.caddy`, которую добавил наш предыдущий установщик корневого домена. Сам старый файл сохраняется.
- Сначала проверяет кандидат конфигурации настоящим Caddy, сохраняет резервную копию текущего Caddyfile, затем перезагружает сервис. При ошибке перезагрузки восстанавливает предыдущие настройки.
- Проверяет HTML игры и байты production-JavaScript по публичному HTTPS.

Если блок бота отличается от предоставленного владельцем, скрипт останавливается до изменения рабочего Caddyfile. DNS и файлы других приложений скрипт не редактирует.

Успех подтверждается строкой:

```text
READY: https://bot.razdorhouse.ru/racing/
```

Этот адрес укажите в BotFather через `/setmenubutton` с подписью «Играть».

## Проверка

Локально проверены синтаксис Bash, адаптация и валидация настоящим Caddy 2.10.2, первый и повторный запуск, сохранность блоков других сайтов, остановка при изменённом блоке бота и откат при сбое перезагрузки. Работа systemd и публичного HTTPS в этих сценариях имитировалась.

Отдельный реальный локальный HTTP-запуск Caddy подтвердил редирект `/racing` → `/racing/`, загрузку индекса и JavaScript игры через префикс и передачу остальных запросов прежнему backend. Новый маршрут на сервере владельца пока не проверен.

## История пакета

В `releases/coastline-server.tar.gz` сохранён уже установленный первоначальный пакет. Его встроенный `deploy-coastline.sh` был рассчитан на свободный корневой домен. Он сохраняется для воспроизводимости, но текущая схема с действующим отдельным основным сайтом использует миграцию `use-bot-domain.sh`, описанную выше.
