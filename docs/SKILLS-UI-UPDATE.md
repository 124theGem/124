# Навыки и интерфейс — 0.6.0 / сервер 0.28.0

Каждый из 16 классов имеет два обычных навыка и ультимейт (48 способностей). У жреца удалено очищение, у ледяного мага — морозная ловушка, у остальных — прежний третий обычный навык. Идентификаторы сохранённых способностей не меняются. Кулдауны, анимации, ИИ, заряд ульты и клавиши 1–3 работают с новым составом; ультимейт определяется по свойству, а не по фиксированному четвёртому слоту.

Три боевые иконки находятся непосредственно слева от кнопки атаки. Меню героя использует три вкладки, карточку выбранного навыка, показатели перезарядки/ресурса/дальности, схему зоны и демонстрацию любого навыка. Переключение вкладок сохраняет живой 3D-просмотр героя.

Ближний взмах показывает сектор фактического угла и дальности (общие параметры с расчётом попаданий), копьё и выстрелы — коридор, площадные умения — круг приземления с траекторией, стена — поперечный отрезок. Сектор обрезается препятствиями вдоль каждого луча. Рассекающий удар берсерка также использует направленный сектор. Корни друида заменены на Порыв природы: летящий заряд, 160 урона в радиусе 3,5 м и радиальное отбрасывание на 3 м, без обездвиживания.

Лечение жреца использует предоставленный пользователем healing_skill_vfx.zip: RGBA-атлас public/vfx/healing/heal_vfx_atlas_6x6.png, 36 кадров 320×320, 24 FPS, однократная анимация 1,5 с в месте фактического лечения. Один SpriteManager на сцену, лимит 20 эффектов, очистка при смене матча. Код из архива служил примером интеграции; VFX не меняет HP. Авторские сведения сохранены рядом с текстурой.

Для выпуска выполняется производственная сборка без полного прогона тестов и браузерных сценариев по просьбе пользователя.
