# Tank Ultimate — Impact & Shield Ward (HD)

Оригинальный игровой VFX под изометрическую мобильную Action RPG, вдохновлённый принципами читаемости Brawl Stars, **не копия ассетов Supercell**.

**Тайминг:** 0–1 с яркий удар о землю и AOE-взрыв; 1–4 с — восемь самостоятельных щитов по большому кругу, мягко пульсирующее энергетическое кольцо. Щиты исчезают к концу четвёртой секунды.

## Содержимое

- `assets/impact_hd_4k_4x4.png` — HD-атлас **4096×4096**, 16 кадров **1024×1024**, прозрачность RGBA.
- `assets/impact_mobile_2k_4x4.png` — экономичный атлас **2048×2048**, 16 кадров **512×512**, прозрачность RGBA.
- `assets/shield_emblem_hd_1024.png` — один HD-щит **1024×1024**, прозрачность RGBA.
- `assets/shield_emblem_mobile_512.png` — облегчённый щит **512×512**.
- `assets/shield_emblem_vector.svg` — исходный вектор щита, масштабируется без потери качества.
- `src/tankUltimateVfx.ts` — модуль Babylon.js, использует два визуальных слоя и реальные кольцевые геометрические объекты.
- `previews/tank_ultimate_4s.gif`, `previews/tank_ultimate_4s.webp` — просмотр полной последовательности 1+3 с.
- `generate_assets.py` — воспроизводимый исходный скрипт генерации атласов и превью (Pillow и CairoSVG).

### Установка в уже существующую игру

1. Скопировать PNG из `assets` в `public/assets/vfx/tank-ultimate/` вашего Vite/Babylon.js проекта.
2. Скопировать `src/tankUltimateVfx.ts` в `src/game/vfx/tankUltimateVfx.ts`.
3. На событии **приземления танка**, а не в начале прыжка, вызвать:

```ts
import { playTankUltimateVfx } from './game/vfx/tankUltimateVfx';

// scene: Babylon Scene; landingPoint: Vector3 — точка попадания танка на землю
const handle = playTankUltimateVfx(scene, landingPoint, {
  radius: 5.5,                  // мир. единицы / метры игрового движка
  quality: 'mobile',            // 'hd' — при достаточных ресурсах устройства
  shields: 8,
  onImpact: (center, radius) => {
    // ВЫЗВАТЬ игровую систему урона здесь (НЕ рисовать через VFX).
    // dealAreaDamage(center, radius, damage);
  },
});

// handle.stop() досрочно уничтожит VFX, например при смене сцены.
```

В течение 1 секунды работает взрыв, затем на 3 секунды включаются отдельные щиты и кольцевые Mesh. Не нужно анимировать весь радиус одним растянутым изображением.

### Особенности мобильной графики

- На многих телефонах 4K RGBA-атлас занимает до ~64 МиБ видеопамяти, даже если PNG весит всего несколько МБ. 2K — около 16 МиБ. Выбирайте `quality: 'mobile'` по умолчанию.
- Размер круга определяется **параметром `radius`**, а размер щитовой текстуры остаётся 512–1024 px независимо от радиуса. Само кольцо — 3D-геометрия.
- Атласы 4×4 без padding; для избежания bleeding выключены mipmaps и установлен CLAMP. При доработке ассетов лучше добавить 2–4 px gutter по краям тайлов.
- Шейдерная подсветка (glow layer) — опциональна; не нужна для базовой работы.
- Событие `onImpact` выполняется в момент запуска эффекта — в боевой логике оно должно совпадать с приземлением.
- **Нет сетевого кода, UI и отдельной демо-игры.** Модуль предназначен для существующего проекта.

### Что НЕ было проверено

Файлы PNG, прозрачность, тайминги превью и ZIP сформированы локально. Конкретную работу модуля внутри вашего проекта Babylon.js необходимо проверить в игровой сцене: расположение над землёй, порядок кадров UV, игровую систему урона и производительность на телефоне.
