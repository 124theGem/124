# Home Codex — телефон → домашний ПК

Личный Telegram-бот запускает Codex CLI на **домашнем компьютере с Windows 10 / WSL2**, в отдельной копии игрового проекта. Сообщения становятся заданиями, очередь и результаты сохраняются в SQLite. Принципиально это новый локальный сеанс Codex с файлами проекта и кратким контекстом последних трёх завершённых задач: текущий облачный чат автоматически туда не переносится.

Игровой бот и VPS не используются для управления ПК. Исходящие HTTPS-запросы к Telegram/OpenAI/GitHub; открывать входящие порты или передавать пароль Windows не требуется. Реальный бот, авторизация владельца и ПК подключаются только при локальной настройке. Здесь нет встроенных токенов.

## 1. Windows 10

Нужна сборка 19041 или новее, виртуализация и WSL2. У владельца подтверждена Windows 10 19045; компоненты Microsoft-Windows-Subsystem-Linux и VirtualMachinePlatform уже включены.

В PowerShell **от имени администратора**:

```powershell
wsl --install -d Ubuntu
```

Если имя дистрибутива не находится, используйте `wsl --list --online` и точное имя из списка. Не полагайтесь на наличие `Ubuntu-24.04` в старом каталоге WSL.

Если установка WSL пишет «Сетевая папка недоступна», при включённых компонентах следующий диагностический шаг — прямая загрузка обновления:

```powershell
wsl --update --web-download
```

Если команда печатает справку, где `--web-download` указан внутри `--install`, используйте поддерживаемую именно этим установщиком форму:

```powershell
wsl --install --web-download -d Ubuntu
```

Это не гарантированное лечение любой сетевой ошибки; вывод команды определяет следующий шаг. Не меняйте DNS/брандмауэр наугад.

После установки и требуемой Windows перезагрузки откройте Ubuntu из меню «Пуск», создайте обычного пользователя Linux и пароль (символы при вводе пароля не отображаются). Проверьте в PowerShell:

```powershell
wsl --list --verbose
```

У Ubuntu в столбце VERSION должно быть **2**. Для перехода с WSL1: `wsl --set-version Ubuntu 2`. Имя должно совпадать со списком. Установщик ниже откажется работать в WSL1 и под root.

## 2. Установка в окне Ubuntu

```bash
curl -fLSs https://raw.githubusercontent.com/124theGem/124/home-codex/home-codex/install.sh -o /tmp/install-home-codex.sh
bash /tmp/install-home-codex.sh
```

Сначала можно прочитать скачанный файл. Скрипт устанавливает базовые Ubuntu-пакеты, официальный Node 24 с проверкой SHA-256, Codex CLI **0.164.0**, GitHub CLI, отдельную копию бота и отдельную копию `124theGem/124` в `~/home-codex-projects/124`. Имеющийся рабочий проект не перезаписывается. Начальная рабочая ветка — `home-pc`, исходник — актуальный `little-planets-mvp`. Повторный запуск не сбрасывает файлы или текущую ветку существующей копии.

Новых глобальных настроек Codex, игровых системных служб, сервера, DNS, Caddy и street-racing скрипт не меняет. Установка требует интернет и разрешение `sudo` внутри Ubuntu. На Ubuntu должны работать обычные HTTPS-загрузки и пакетный менеджер.

## 3. Вход на самом ПК

В том же окне Ubuntu:

```bash
export PATH="$HOME/.local/share/home-codex/node/bin:$HOME/.local/share/home-codex/tools/bin:$PATH"
codex login
```

Войдите в свой аккаунт ChatGPT с доступом к Codex через выданный браузерный адрес. Это расходует обычные лимиты вашего плана, не предоставляет безлимитную бесплатную работу. При необходимости доступен `codex login --device-auth`; настройки аккаунта должны разрешать такой вход. Проверка: `codex login status`. Коды входа и токены не отправляйте в чат.

Для публикации в своём GitHub:

```bash
gh auth login
# GitHub.com → HTTPS → вход через браузер
gh auth setup-git
```

Задайте автора коммитов **в новой копии проекта**:

```bash
git -C "$HOME/home-codex-projects/124" config user.name "YOUR_NAME"
git -C "$HOME/home-codex-projects/124" config user.email "YOUR_GITHUB_EMAIL"
```

Можно использовать свой noreply email из GitHub. Для локальной сборки игры:

```bash
cd "$HOME/home-codex-projects/124/little-planets"
npm ci
npm run build
```

Браузерные проверки дополнительно требуют Chromium/Playwright и его системных библиотек в Ubuntu. Установщик базового бота их автоматически не ставит.

## 4. Привязка отдельного Telegram-бота

В Telegram откройте **@BotFather**, выполните `/newbot` и создайте **нового отдельного бота**. Не используйте токен игровой Mini App.

В Ubuntu:

```bash
bash "$HOME/.local/share/home-codex/setup.sh"
```

Для папки проекта нажмите Enter — предлагается `~/home-codex-projects/124/little-planets`. Токен введите здесь же: ввод скрыт, он не помещается в историю команд и хранится в `~/.config/home-codex/config.json` с правами 0600. Если у бота уже настроен webhook, программа откажется запускаться и ничего не заменит.

Терминал выдаст адрес вашего бота и команду `/pair СЛУЧАЙНЫЙ_КОД` на 15 минут. Запустите обработчик:

```bash
bash "$HOME/.local/share/home-codex/run.sh"
```

Отправьте указанную `/pair ...` **новому боту в личные сообщения со своего телефона**. Первый верный код привязывает ваш числовой Telegram ID; остальные аккаунты и групповые чаты игнорируются. Код одноразовый. Если он истёк — остановите обработчик Ctrl+C и повторите настройку. После привязки она сохраняется при перезапуске.

Теперь пишите, например:

> В RIFT RAID увеличь размер героя на 15%, проверь сборку и тесты. Опубликуй серверный архив и продвинь обновление через существующий канал little-planets-mvp.

## 5. Команды и поведение

- Обычный текст — новая задача. До 20 ожидающих/выполняющихся задач, один процесс Codex одновременно.
- `/status` — ПК на связи, очередь последних восьми задач.
- `/result 12` — сохранённый результат.
- `/cancel 12` — отменить ожидающую задачу или остановить выполняющийся процесс. Уже изменённые файлы не откатываются.
- `/help` — справка.

Поддерживаются текстовые задания и отправка до трёх итоговых PNG/JPG, созданных Codex в `.home-codex/outbox/НОМЕР/` внутри проекта. Входящие вложения пока не обрабатываются. Для описаний можно использовать голосовой ввод клавиатуры телефона → текст.

Публикация не выполняется по факту получения любого сообщения: укажите её в задании, если нужна. Работает обычный Codex `workspace-write` и автоматическое рассмотрение запросов `--approve-for-me`, без отключения sandbox. Разрешён сетевой доступ для зависимостей и GitHub. Отказ согласования, лимит аккаунта, недоступная сеть или авторизация могут оставить задачу незавершённой — бот показывает ошибку, а не объявляет несуществующий успех. Финальный текст Codex не является отдельной независимой аттестацией результата.

Повторная доставка Telegram одного update не создаёт дубликат задачи. При аварийном перезапуске выполнявшаяся задача получает `interrupted` и не повторяется автоматически: изменения могли уже произойти. Ожидающие задачи сохраняются. Лимит одного запуска — два часа; отмена и лимит завершают всю POSIX-группу процесса. Блокировка `flock` защищает от двух обработчиков одновременно; используйте `run.sh`, а не прямой запуск app.mjs.

Результаты, задания и частные журналы — `~/.local/share/home-codex/state`. Они не публикуются в репозиторий. Старые журналы можно удалять после завершения соответствующих задач. Простое удаление истории не откатывает изменения проекта. Рабочая копия не обновляется принудительно и не очищается при каждом старте.

## 6. Автозапуск Windows

Сначала убедитесь, что бот отвечает и завершил маленькое тестовое задание. Сохраните [autostart.ps1](autostart.ps1) на ПК и запустите в обычном PowerShell **под тем же пользователем Windows**, который настроил Ubuntu:

```powershell
powershell -ExecutionPolicy Bypass -File .\autostart.ps1 -Distro Ubuntu
Start-ScheduledTask -TaskName HomeCodexTelegram
```

Создаётся задача текущего пользователя при входе в Windows, без запуска под SYSTEM или повышения до администратора. Если название дистрибутива другое — передайте его в `-Distro`. Автозапуск не обходит экран входа: после перезагрузки нужно войти в Windows. До этого бот будет офлайн.

Компьютер должен быть включён, с интернетом и не спать. Сон настройте вручную в параметрах питания; скрипт сам их не меняет. Остановить: `Stop-ScheduledTask -TaskName HomeCodexTelegram`. Удалить автозапуск: `Unregister-ScheduledTask -TaskName HomeCodexTelegram`. Во время первого ручного запуска Ctrl+C останавливает бота и активное задание.

## Проверки поставки

`node --test tests/*.test.mjs`: 11 проверок — привязка и чужой аккаунт, срок кода, повторные update, долговечность/восстановление очереди, последовательность задач, отмена, редактирование секретов перед разбивкой сообщений, защита вложений, настоящая передача stdin подставному процессу Codex, лимит времени и ошибки. Реальный Codex 0.164.0 скачан отдельно и его параметры проверены через `--help`. `bash -n` проверяет shell-скрипты.

Это проверки в Linux-облаке с подставным Telegram и подставным исполнителем задач: на ваш ПК ничего автоматически не установлено, реальные Telegram-сообщения/задания моделям не отправлялись. Полная проверка Windows/WSL, входа аккаунта, GitHub push и автозапуска выполняется на домашнем ПК после устранения текущей ошибки установки WSL. Windows PowerShell-скрипт в этой Linux-среде не запускался.

Официальные источники: [Codex CLI](https://github.com/openai/codex#installing-and-running-codex-cli), [WSL install](https://learn.microsoft.com/windows/wsl/install), [GitHub CLI](https://cli.github.com/).
